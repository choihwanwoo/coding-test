# 코딩테스트 연습 - 뒤집힌 문자열 (LV.0)

## 풀이

**1. 문자열을 뒤에서부터 읽으면 된다.**

`my_string`의 마지막 글자부터 첫 글자까지 읽으면 뒤집힌 문자열이 된다.

<span style="color:red">ex)</span> `"jaron"` → `"noraj"`

**2. `[::-1]`은 문자열 전체를 거꾸로 읽는다.**

```python
"bread"[::-1]  # "daerb"
```

슬라이싱의 간격을 `-1`로 지정하면 뒤에서 앞으로 한 글자씩 선택한다.

---

## 오답노트

```python
my_string.reverse()  # ❌
```

문자열은 변경할 수 없는 자료형이라 `reverse()` 메서드가 없다. `reversed()`를 쓸 수도 있지만 `''.join()`이 추가로 필요하므로, 이 문제에서는 슬라이싱이 가장 간단하다.

---

## 정답

```python
def solution(my_string):
    return my_string[::-1]
```

### 한 줄 요약
