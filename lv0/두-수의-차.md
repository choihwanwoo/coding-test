# 코딩테스트 연습 - 두 수의 차 구하기 (LV.0)

## 풀이

1. 정수 `num1`, `num2`가 주어지면 `num1 - num2`를 return 한다.

2. 제한사항 `-50000 ≤ num1, num2 ≤ 50000`은 입력이 그 범위라는 보장이다.

그러므로 범위 검사를 코드에 넣을 필요 없이, 빼기만 하면 된다고 생각하였다.

---

## 정답

```java
class Solution {
    public int solution(int num1, int num2) {
        int answer = 0;
        answer = num1 - num2;
        return answer;
    }
}
```
