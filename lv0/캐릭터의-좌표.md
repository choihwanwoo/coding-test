# 코딩테스트 연습 - 캐릭터의 좌표 (LV.0)

## 풀이

**1. `[0, 0]`에서 시작해서 키 입력대로 움직인다**

- `up` → y + 1
- `down` → y - 1
- `left` → x - 1
- `right` → x + 1

`keyinput`을 순서대로 돌면서 좌표를 바꾸면 된다고 생각하였다

<br>

**2. 맵 밖으로 나가면 그 입력은 무시한다**

`board = [가로, 세로]`이고, `[0, 0]`이 **가운데**다

가로는 홀수라서, 갈 수 있는 x 범위는

```python
max_x = board[0] // 2
```

세로도 마찬가지다

```python
max_y = board[1] // 2
```

<span style="color:red">ex)</span> `board = [7, 9]`

- x: `-3 ~ 3` (`7 // 2 = 3`)
- y: `-4 ~ 4` (`9 // 2 = 4`)

`down`을 5번 눌러도 y는 `-5`가 아니라 **`-4`에서 멈춘다**

<br>

**3. 움직이기 전에 “가도 되는지” 확인한다**

```python
nx, ny = x, y

if key == "up":
    ny += 1
elif key == "down":
    ny -= 1
elif key == "left":
    nx -= 1
elif key == "right":
    nx += 1

if -max_x <= nx <= max_x and -max_y <= ny <= max_y:
    x, y = nx, ny
```

다음 좌표 `nx, ny`를 먼저 계산하고  
범위 안일 때만 실제 좌표를 바꾼다

범위 밖이면 그냥 무시하고 다음 키로 넘어간다

<span style="color:red">ex)</span> `["left", "right", "up", "right", "right"]`, `board = [11, 11]`

| 입력 | 이동 후 | 비고 |
|------|---------|------|
| left | `[-1, 0]` | |
| right | `[0, 0]` | |
| up | `[0, 1]` | |
| right | `[1, 1]` | |
| right | `[2, 1]` | 결과 |

---

## 오답노트

**1. 범위 체크 없이 움직이면 맵 밖으로 나간다**

<span style="color:red">ex)</span> `down` 5번, `board = [7, 9]`

- 체크 없으면 → `[0, -5]` ❌
- 체크 있으면 → `[0, -4]` ✅

끝까지 간 다음 `min`/`max`로 자르는 방법도 있지만,  
문제 뜻은 **밖으로 나가는 입력을 무시**하는 거라  
미리 확인하고 안 가는 편이 맞다

<br>

**2. 가로·세로 한도를 헷갈리면 안 된다**

- `board[0]` → 가로 → **x** 한도
- `board[1]` → 세로 → **y** 한도

`max_x = board[0] // 2`, `max_y = board[1] // 2`로 나눠서 쓴다

<br>

**3. `up`/`down`은 x가 아니라 y다**

- `up` / `down` → **y**
- `left` / `right` → **x**

축을 바꾸면 좌표가 전부 틀어진다

---

## 정답

```python
def solution(keyinput, board):
    x, y = 0, 0
    max_x = board[0] // 2
    max_y = board[1] // 2

    for key in keyinput:
        nx, ny = x, y
        if key == "up":
            ny += 1
        elif key == "down":
            ny -= 1
        elif key == "left":
            nx -= 1
        elif key == "right":
            nx += 1

        if -max_x <= nx <= max_x and -max_y <= ny <= max_y:
            x, y = nx, ny

    return [x, y]
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `x, y = 0, 0` | 가운데에서 시작 |
| `max_x = board[0] // 2` | 가로로 갈 수 있는 최대 거리 |
| `max_y = board[1] // 2` | 세로로 갈 수 있는 최대 거리 |
| `nx, ny = x, y` | 다음 좌표 후보 |
| `if -max_x <= nx <= max_x ...` | 맵 안일 때만 이동 |
| `return [x, y]` | 최종 좌표 |
