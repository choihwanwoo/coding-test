# 코딩테스트 연습 - 구슬을 나누는 경우의 수 (LV.0)

## 풀이

**1. 순서를 고려하지 않으므로 조합이다.**

`balls`개 중 `share`개를 고르는 순서는 결과에 영향을 주지 않는다. 따라서 답은 `balls C share`다.

```
nCr = n! / (r! × (n - r)!)
```

**2. 작은 쪽을 선택해 반복 횟수를 줄인다.**

`nCr = nC(n-r)`이므로 `share`와 `balls - share` 중 작은 값을 사용한다.

**3. 팩토리얼 전체를 만들지 않고 계산한다.**

각 반복에서 분자를 곱하고 분모를 나누면 조합을 정수로 계산할 수 있다.

---

## 오답노트

```python
for i in range(share):
    answer *= balls - i  # ❌
```

이 식은 고르는 순서까지 세는 순열이다. 조합은 같은 구슬 묶음의 순서를 한 번만 세야 한다.

---

## 정답

```python
def solution(balls, share):
    share = min(share, balls - share)
    answer = 1

    for i in range(1, share + 1):
        answer *= balls - share + i
        answer //= i

    return answer
```

### 한 줄 요약

> 순서를 고려하지 않는 선택이므로 조합을 반복 곱셈과 나눗셈으로 계산한다.
