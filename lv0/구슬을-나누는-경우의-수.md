# 코딩테스트 연습 - 구슬을 나누는 경우의 수 (LV.0)

## 풀이

**1. 순서를 고려하지 않으므로 조합이다.**

`balls`개의 서로 다른 구슬 중에서 친구들에게 줄 `share`개를 고르는 문제다.

`A → B` 순서로 고르든 `B → A` 순서로 고르든 같은 구슬 묶음이므로, 순서를 세는 순열이 아니라 **조합**을 사용한다.

```
balls C share
```

조합 공식은 다음과 같다.

```
nCr = n! / (r! × (n - r)!)
```

여기서 `n = balls`, `r = share`다.

<span style="color:red">ex)</span> 구슬이 `3개`이고 그중 `2개`를 고를 때

```
{1, 2}, {1, 3}, {2, 3}
```

총 `3개`이므로 `3C2 = 3`이다.

<br>

**2. `share`개를 고르는 일과 남은 구슬을 고르는 일은 같다.**

`nCr`은 `nC(n-r)`과 같다.

<span style="color:red">ex)</span>

```
5C3 = 5C2 = 10
```

5개 중 3개를 친구에게 주는 방법은, 반대로 내가 남길 2개를 고르는 방법과 같다.

그래서 반복 횟수를 줄이기 위해 더 작은 값을 사용한다.

```python
share = min(share, balls - share)
```

<br>

**3. 팩토리얼 전체를 구하지 않고 하나씩 나눈다.**

조합은 다음처럼도 계산할 수 있다.

```
nCr = (n-r+1) / 1 × (n-r+2) / 2 × ... × n / r
```

반복문 안에서 곱한 뒤 바로 나누면 된다.

```python
answer *= balls - share + i
answer //= i
```

`i`번째 반복까지의 결과는 항상 정수이므로 `//`로 나눌 수 있다.

<span style="color:red">ex)</span> `5C3` 계산 (`share`를 `2`로 바꾼 뒤)

```
처음 answer = 1
i = 1 → 1 × 4 ÷ 1 = 4
i = 2 → 4 × 5 ÷ 2 = 10
```

## 오답노트

**1. 순열 공식으로 계산하면 같은 조합을 여러 번 센다.**

```python
answer = 1
for i in range(share):
    answer *= balls - i  # ❌
```

이 값은 `nPr`처럼 순서까지 고려한 결과다.

`balls = 3`, `share = 2`이면 `3 × 2 = 6`이 되지만, `{1, 2}`와 `{2, 1}`은 같은 경우이므로 답은 `3`이어야 한다.

조합으로 만들려면 `share!`만큼 나눠야 한다.

<br>

**2. 나눗셈을 마지막에 `/`로 하면 실수가 된다.**

```python
answer = numerator / denominator  # ❌
```

`/`는 `float`를 반환한다.

이 문제의 답은 정수이므로, 계산 과정에서 `//`를 사용하거나 마지막 결과를 정수로 만들어 반환해야 한다.

<br>

**3. `share`가 `balls`와 같을 때도 처리된다.**

모든 구슬을 고르는 방법은 한 가지다.

```python
share = min(balls, balls - balls)  # 0
```

반복문이 실행되지 않고 `answer = 1`이 그대로 반환된다.

---

## 정답

```python
def solution(balls, share):
    share = min(share, balls - share)
    answer = 1

    for i in range(1, share + 1):
        answer *= balls - share + i
        answer //= i

    return answer
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `min(share, balls - share)` | 같은 조합 중 반복 횟수가 더 적은 쪽 선택 |
| `answer = 1` | 곱셈 계산의 시작값 |
| `range(1, share + 1)` | 조합에서 필요한 분모 `1`부터 `share`까지 반복 |
| `balls - share + i` | 분자의 연속된 값들을 곱함 |
| `answer //= i` | 매 단계의 분모를 나눔 |

### 한 줄 요약

> 순서를 고려하지 않는 선택이므로 조합을 사용하며, `nCr`을 반복 곱셈과 나눗셈으로 계산한다.
