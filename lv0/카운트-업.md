# 코딩테스트 연습 - 카운트 업 (LV.0)

## 풀이

**1. 시작 숫자부터 끝 숫자까지 순서대로 담으면 된다.**

정수 `start_num`부터 `end_num`까지 **두 숫자를 모두 포함해서** 리스트로 반환하는 문제다.

<span style="color:red">ex)</span> `start_num = 3`, `end_num = 10`

```python
[3, 4, 5, 6, 7, 8, 9, 10]
```

숫자가 1씩 커지니까 Python의 `range`를 사용하면 된다.

<br>

**2. `range`는 끝 숫자를 포함하지 않는다.**

```python
range(start_num, end_num + 1)
```

`range(시작, 끝)`은 시작 숫자부터 **끝 숫자 직전까지** 만든다.

그래서 `end_num`까지 넣으려면 끝에 `1`을 더해야 한다.

<span style="color:red">ex)</span>

- `range(3, 10)` → `3`부터 `9`까지
- `range(3, 11)` → `3`부터 `10`까지

간격은 기본값이 `1`이라서 따로 적지 않아도 된다.

<br>

**3. `list()`로 리스트를 만들어 반환한다.**

```python
answer = list(range(start_num, end_num + 1))
```

`range` 자체는 리스트가 아니라 숫자 범위를 나타내는 객체다.

문제에서 리스트를 요구하니까 `list()`로 변환한다.

---

## 오답노트

**1. `end_num`을 그대로 넣으면 마지막 숫자가 빠진다.**

```python
list(range(3, 10))
# [3, 4, 5, 6, 7, 8, 9] ❌
```

`10`까지 포함해야 하니까 `end_num + 1`을 넣어야 한다.

```python
list(range(3, 11))
# [3, 4, 5, 6, 7, 8, 9, 10] ✅
```

<br>

**2. `range`를 대괄호로 감싸는 것과 `list()`는 다르다.**

```python
[range(3, 11)]
# [range(3, 11)] ❌
```

대괄호로 감싸면 숫자들이 아니라 **range 객체 하나**가 리스트에 들어간다.

각 숫자를 원소로 넣으려면 `list(range(3, 11))`을 사용해야 한다.

<br>

**3. 시작 숫자와 끝 숫자가 같아도 그 숫자는 포함해야 한다.**

제한사항에서 `start_num <= end_num`이므로 두 숫자가 같을 수도 있다.

<span style="color:red">ex)</span> `start_num = 5`, `end_num = 5`

```python
list(range(5, 6))
# [5]
```

`end_num + 1`을 사용하면 별도의 조건문 없이 처리된다.

---

## 정답

```python
def solution(start_num, end_num):
    answer = list(range(start_num, end_num + 1))
    return answer
```

### 한 줄씩

- `range(start_num, end_num + 1)` → 시작 숫자부터 끝 숫자까지 1씩 증가하는 범위
- `list(...)` → 범위 안의 숫자들을 리스트로 변환
- `return answer` → 완성된 리스트 반환

### 한 줄 요약

> `range`는 끝값을 포함하지 않으므로, `end_num + 1`까지 범위를 잡고 리스트로 변환하면 된다.
