# 코딩테스트 연습 - 특이한 정렬 (LV.0)

## 풀이

**1. `n`과 가까운 순서대로 정렬하면 된다**

`numlist`의 각 숫자가 `n`에서 얼마나 떨어져 있는지 보면 된다

거리는 `abs(숫자 - n)`으로 구할 수 있다고 생각하였다

<span style="color:red">ex)</span> `numlist = [1, 2, 3, 4, 5, 6]`, `n = 4`

| 숫자 | n과의 거리 |
|------|-----------|
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |
| 4 | 0 |
| 5 | 1 |
| 6 | 2 |

가까운 순 → `4 → 5, 3 → 6, 2 → 1`

<br>

**2. 거리가 같으면 큰 수가 먼저다**

`n = 4`일 때 `3`과 `5`는 둘 다 거리가 `1`이다

이때는 **더 큰 수**인 `5`가 먼저 와야 한다

`2`와 `6`도 거리가 `2`로 같으니 `6`이 먼저다

<br>

**3. `sorted`에 `key`를 주면 된다**

정렬 기준을 튜플로 넣으면 된다

```python
sorted(numlist, key=lambda x: (abs(x - n), -x))
```

- 첫 번째 기준 `abs(x - n)` → `n`과 가까운 순
- 두 번째 기준 `-x` → 거리가 같을 때 큰 수가 앞으로

<span style="color:red">ex)</span> `5`와 `3` 비교

- `5` → `(1, -5)`
- `3` → `(1, -3)`
- 튜플은 앞에서부터 비교하니까 거리 `1`은 같고, `-5 < -3`이라 `5`가 먼저

<br>

**4. `abs`는 절댓값이다**

`n`보다 작은 수든 큰 수든, 그냥 차이만 보면 된다

```python
abs(3 - 4)   # 1
abs(5 - 4)   # 1
abs(6 - 4)   # 2
```

## 오답노트

**1. 거리만 보고 정렬하면 동률 처리가 틀린다**

```python
sorted(numlist, key=lambda x: abs(x - n))  # ❌
```

거리가 같을 때 파이썬 기본 정렬 순서에 맡기면, 문제에서 원하는 **큰 수 우선**이 안 나온다

<span style="color:red">ex)</span> `n = 4`일 때 `3`과 `5`

- 거리만 보면 둘 다 `1`
- 문제 조건 → `5`가 먼저
- 그래서 두 번째 기준이 필요하다

<br>

**2. 큰 수 우선을 `x`로 쓰면 반대로 된다**

```python
sorted(numlist, key=lambda x: (abs(x - n), x))  # ❌
```

거리가 같을 때 `x`를 오름차순으로 비교하면 **작은 수**가 먼저 온다

큰 수를 먼저내려면 `-x`를 쓴다

<span style="color:red">ex)</span> `3`과 `5`

- `(1, 3)` vs `(1, 5)` → `3`이 먼저 ❌
- `(1, -3)` vs `(1, -5)` → `5`가 먼저 ✅

<br>

**4. `numlist.sort()`를 `return`하면 런타임 에러 난다**

```python
return numlist.sort(key=lambda x: (abs(x - n), -x))  # ❌
```

`sort()`는 정렬만 하고 **`None`을 반환**한다

그래서 `return`하면 `None`이 돌아가서 에러가 난다

반드시 `sorted()`를 쓰거나, `sort()` 후 `return numlist`를 해야 한다

<br>

**5. `sorted`는 원본을 안 바꾼다**

`numlist.sort(...)`도 가능하지만, 원본 배열이 바뀐다

`return sorted(...)`로 새 리스트를 만들어 반환하면 된다

---

## 정답

```python
def solution(numlist, n):
    return sorted(numlist, key=lambda x: (abs(x - n), n - x))
```

`n - x`도 `-x`랑 같은 역할이다  
거리가 같을 때 `n - x`가 더 작은 쪽 = 더 큰 `x`가 먼저 온다

<span style="color:red">ex)</span> `n = 4`일 때

- `5` → `(1, -1)`
- `3` → `(1, 1)`
- `-1 < 1` 이라 `5`가 먼저

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `sorted(numlist, ...)` | numlist를 정렬한 새 리스트 |
| `key=lambda x: ...` | 각 숫자마다 정렬 기준을 정함 |
| `abs(x - n)` | n과의 거리 |
| `n - x` | 거리가 같을 때 큰 수 우선 |
