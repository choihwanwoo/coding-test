# 코딩테스트 연습 - 짝수는 싫어요 (LV.0)

## 풀이

**1. 입력이 배열이 아니라 `int n`이다.**

초기 화면은 이렇다.

```java
class Solution {
    public int[] solution(int n) {
        int[] answer = {};
        return answer;
    }
}
```

`n` 이하의 **홀수만** 모아서 배열로 반환하면 된다.

<span style="color:red">ex)</span>

- `n = 10` → `[1, 3, 5, 7, 9]`
- `n = 15` → `[1, 3, 5, 7, 9, 11, 13, 15]`

<br>

**2. 홀수는 `i % 2 == 1`로 판별한다.**

어떤 수를 2로 나눈 **나머지가 1**이면 홀수다.

```java
if (i % 2 == 1) {
    // 홀수
}
```

<br>

**3. 결과 배열 길이는 `(n + 1) / 2`로 잡는다.**

`int[] answer = {}`는 칸이 0개라서 값을 못 넣는다.

`n` 이하 홀수 개수는 `(n + 1) / 2`개다.

- `n = 10` → `(10 + 1) / 2 = 5`
- `n = 15` → `(15 + 1) / 2 = 8`

그래서 `new int[(n + 1) / 2]`로 만든다.

<br>

**4. `1`부터 `n`까지 돌면서 홀수만 넣는다.**

```java
for (int i = 1; i <= n; i++) {
```

- `i = 1`에서 시작
- `i <= n` → `i`가 `n` **이하**일 때까지 반복 (`n` 포함)
- `i++` → 한 번 돌 때마다 1씩 증가

홀수면 `answer[idx]`에 넣고 `idx++`로 다음 칸으로 이동한다.

---

## 오답노트

**1. 처음에 배열에 `%`를 걸려고 했다.**

```java
array%2=1;
```

이건 안 된다.

- 이 문제 입력은 `int[] array`가 아니라 `int n`
- `%`는 배열 전체가 아니라 **숫자 하나**에 씀
- 비교는 `=`가 아니라 `==`

올바른 형태:

```java
if (i % 2 == 1) { ... }
```

<br>

**2. `int[] answer = {}`를 그대로 두면 안 된다.**

칸이 0개라서 홀수를 넣을 자리가 없다.

`(n + 1) / 2` 길이로 바꿔야 한다.

<br>

**3. `i < n`이랑 `i <= n`을 헷갈렸다.**

| 조건 | 의미 |
|------|------|
| `i < n` | `n` 직전까지만 (`n` 미포함) |
| `i <= n` | `n`까지 포함 |

문제는 **`n` 이하** 홀수라서 `i <= n`이 맞다.

---

## 정답

```java
class Solution {
    public int[] solution(int n) {
        int[] answer = new int[(n + 1) / 2];
        int idx = 0;

        for (int i = 1; i <= n; i++) {
            if (i % 2 == 1) {
                answer[idx] = i;
                idx++;
            }
        }

        return answer;
    }
}
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `new int[(n + 1) / 2]` | 홀수 개수만큼 배열 만들기 |
| `int idx = 0` | 넣을 위치 (0번 칸부터) |
| `for (int i = 1; i <= n; i++)` | 1부터 n까지 확인 |
| `if (i % 2 == 1)` | 나머지가 1이면 홀수 |
| `answer[idx] = i` | 그 칸에 홀수 넣기 |
| `idx++` | 다음 칸으로 이동 |
| `return answer` | 결과 배열 반환 |
