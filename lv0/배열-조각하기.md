# 코딩테스트 연습 - 배열 조각하기 (LV.0)

## 풀이

**1. `query`를 순서대로 돌면서 `arr`을 잘라낸다**

`arr`과 `query`가 주어진다

`query`의 인덱스 `i`가

- **짝수**면 → `arr[0]`부터 `arr[query[i]]`까지 남긴다
- **홀수**면 → `arr[query[i]]`부터 끝까지 남긴다

다 돌고 남은 `arr`을 반환하면 된다고 생각하였다

<span style="color:red">ex)</span> `arr = [0, 1, 2, 3, 4, 5]`, `query = [4, 1, 2]`

| i | 짝/홀 | query[i] | 남기는 범위 | arr |
|---|-------|----------|-------------|-----|
| 0 | 짝 | 4 | 0~4 | `[0, 1, 2, 3, 4]` |
| 1 | 홀 | 1 | 1~끝 | `[1, 2, 3, 4]` |
| 2 | 짝 | 2 | 0~2 | `[1, 2, 3]` |

결과: `[1, 2, 3]`

<br>

**2. 파이썬 슬라이싱으로 자른다**

`arr[시작:끝]`은 **끝 인덱스 직전**까지 잘라낸다

짝수일 때 `0`부터 `query[i]` **포함**이려면

```python
arr = arr[:query[i] + 1]
```

홀수일 때 `query[i]`부터 끝이면

```python
arr = arr[query[i]:]
```

`:` 뒤가 비어 있으면 끝까지다

<br>

**3. for문에서 `i`가 짝수/홀수인지 본다**

```python
for i in range(len(query)):
    if i % 2 == 0:
        arr = arr[:query[i] + 1]
    else:
        arr = arr[query[i]:]
```

`i % 2 == 0` → 짝수  
`i % 2 == 1` → 홀수

`query`를 다 돌 때마다 `arr`이 바뀌므로,  
다음 `query[i]`는 **잘린 뒤의 arr** 기준 인덱스다

---

## 오답노트

**1. 짝수일 때 `arr[:query[i]]`만 쓰면 한 칸 부족하다**

`query[i]` **까지 포함**이어야 한다

`arr[:4]`는 인덱스 `0,1,2,3`만 남기고, `4`는 빠진다

그래서 `+ 1`이 필요하다

<span style="color:red">ex)</span> `query[0] = 4`일 때

- `arr[:4]` → `[0, 1, 2, 3]` ❌
- `arr[:5]` → `[0, 1, 2, 3, 4]` ✅

<br>

**2. 홀수/짝수를 query 값이 아니라 for문 인덱스 `i`로 본다**

`query[i]`가 짝수인지 홀수인지가 아니다

**몇 번째 query인지** `i`가 짝수인지 홀수인지다

- `i = 0` (첫 번째) → 짝수 규칙
- `i = 1` (두 번째) → 홀수 규칙

<br>

**3. 슬라이싱이 처음엔 낯설었다**

자바 배열은 `Arrays.copyOfRange` 같은 걸 쓰지만,  
파이썬은 `arr[시작:끝]`으로 한 줄에 자른다

잘린 `arr`을 그대로 다음 루프에 쓰면 된다

---

## 정답

```python
def solution(arr, query):
    for i in range(len(query)):
        if i % 2 == 0:
            arr = arr[:query[i] + 1]
        else:
            arr = arr[query[i]:]
    return arr
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `for i in range(len(query))` | query를 0부터 순서대로 |
| `i % 2 == 0` | i가 짝수 (0, 2, 4…) |
| `arr[:query[i] + 1]` | 0번부터 query[i]까지 남김 |
| `arr[query[i]:]` | query[i]번부터 끝까지 남김 |
| `return arr` | 마지막에 남은 배열 |
