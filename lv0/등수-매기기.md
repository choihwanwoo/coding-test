# 코딩테스트 연습 - 등수 매기기 (LV.0)

## 풀이

**1. 영어 점수와 수학 점수의 평균을 구한다.**

한 학생의 점수는 `score[i][0]`(영어), `score[i][1]`(수학)이다.

평균은 `(영어 + 수학) / 2` 이지만, 등수만 비교하면 되므로 굳이 나누지 않아도 된다.

```python
total = score[i][0] + score[i][1]
```

모든 평균에 똑같이 `2`를 나누는 것이므로, **점수 합이 큰 학생이 평균도 더 크다.**

<span style="color:red">ex)</span>

- `[80, 70]` → 합 `150` → 평균 `75`
- `[90, 50]` → 합 `140` → 평균 `70`
- `[40, 70]` → 합 `110` → 평균 `55`
- `[50, 80]` → 합 `130` → 평균 `65`

<br>

**2. 나보다 평균이 높은 학생 수를 센다.**

등수는 기본적으로 `1등`에서 시작한다.

그래서 어떤 학생보다 평균이 높은 학생이 한 명 있으면 `2등`, 세 명 있으면 `4등`이다.

```python
rank = 1

if my_total < other_total:
    rank += 1
```

<span style="color:red">ex)</span> 첫 번째 학생의 합이 `150`일 때

- 더 큰 합이 `0명` → `1등`

세 번째 학생의 합이 `110`일 때

- 더 큰 합이 `150`, `140`, `130`으로 `3명` → `4등`

<br>

**3. 점수가 같으면 같은 등수이고, 다음 등수는 건너뛴다.**

합이 같으면 평균도 같으므로 둘 다 같은 등수다.

`[80, 70]`, `[70, 80]`은 점수 배열은 다르지만 합이 둘 다 `150`이라 평균은 `75`로 같다.

<span style="color:red">ex)</span> 평균이 `100, 100, 95, 90`이면

- 평균 `100`인 학생은 자기보다 높은 학생이 `0명` → 둘 다 `1등`
- 평균 `95`인 학생은 높은 학생이 `2명` → `3등`
- 평균 `90`인 학생은 높은 학생이 `3명` → `4등`

그래서 공동 1등이 두 명이면 2등은 없다.

## 오답노트

**1. 평균을 `//`로 나누면 소수점이 버려진다.**

```python
average = (score[i][0] + score[i][1]) // 2  # ❌
```

이 문제에서는 두 과목 점수의 합이 항상 짝수인 것은 아니다.

<span style="color:red">ex)</span>

- 합 `151` → 실제 평균 `75.5`
- 합 `150` → 실제 평균 `75`

`//`로 나누면 둘 다 `75`가 되어 잘못 비교할 수 있다.

등수 비교만 할 때는 나누지 않고 **합끼리 비교**하면 안전하다.

<br>

**2. 점수 배열이 중복되지 않아도 평균은 같을 수 있다.**

제한사항의 "`score`는 중복된 원소를 갖지 않습니다"는 `[80, 70]`과 `[80, 70]`처럼 완전히 같은 배열이 없다는 뜻이다.

하지만 `[80, 70]`과 `[70, 80]`은 서로 다른 배열이면서 평균은 같다.

그래서 합이 같은 경우에도 공동 등수를 처리해야 한다.

<br>

**3. 같은 평균까지 세면 등수가 하나씩 밀린다.**

```python
if my_total <= other_total:  # ❌
    rank += 1
```

자기 자신과 평균이 같은 학생까지 세면 안 된다.

나보다 **높은** 평균만 세기 위해 `<`를 사용한다.

```python
if my_total < other_total:  # ✅
    rank += 1
```

## 정답

```python
def solution(score):
    answer = []
    totals = [english + math for english, math in score]

    for my_total in totals:
        rank = 1

        for other_total in totals:
            if my_total < other_total:
                rank += 1

        answer.append(rank)

    return answer
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `totals = [...]` | 학생별 영어 + 수학 점수를 담은 리스트 |
| `for my_total in totals` | 학생 한 명의 점수 합을 꺼냄 |
| `rank = 1` | 모든 학생은 일단 1등에서 시작 |
| `my_total < other_total` | 나보다 평균이 높은 학생인지 확인 |
| `answer.append(rank)` | 구한 등수를 결과 리스트에 추가 |

### 한 줄 요약

> 각 학생마다 나보다 평균이 높은 학생 수를 세고, 그 수에 1을 더하면 등수다.
