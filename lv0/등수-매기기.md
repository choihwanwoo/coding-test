# 코딩테스트 연습 - 등수 매기기 (LV.0)

## 풀이

**1. 평균 대신 점수 합을 비교한다.**

모든 학생의 평균은 점수 합을 `2`로 나눈 값이다. 같은 수로 나누므로 평균이 큰 순서와 점수 합이 큰 순서는 같다.

```python
total = score[i][0] + score[i][1]
```

<br>

**2. 나보다 합이 큰 학생 수에 1을 더하면 등수다.**

기본 등수는 `1`이다. 나보다 평균이 높은 학생이 한 명이면 2등, 세 명이면 4등이 된다. 합이 같으면 더 높은 학생으로 세지 않으므로 공동 등수도 자연스럽게 처리된다.

---

## 오답노트

**1. `// 2`로 평균을 만들어 비교하면 안 된다.**

합이 `151`인 학생과 `150`인 학생의 평균은 각각 `75.5`, `75`이다. 하지만 `// 2`를 하면 둘 다 `75`가 된다. 나누지 않고 합을 비교하면 안전하다.

**2. 같은 평균도 높은 학생으로 세면 안 된다.**

```python
if my_total <= other_total:  # ❌
```

자기 자신과 공동 등수 학생은 제외해야 하므로 `<`를 사용한다.

---

## 정답

```python
def solution(score):
    totals = [english + math for english, math in score]
    answer = []

    for my_total in totals:
        rank = 1
        for other_total in totals:
            if my_total < other_total:
                rank += 1
        answer.append(rank)

    return answer
```

### 한 줄 요약

> 각 학생보다 점수 합이 큰 학생 수를 세고 1을 더하면 등수다.
