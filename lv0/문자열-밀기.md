# 코딩테스트 연습 - 문자열 밀기 (LV.0)

## 풀이

**1. 오른쪽으로 밀면 `A[0]`이 몇 번째 칸으로 가는지 보면 된다**

문자열을 오른쪽으로 한 칸 밀면

- 맨 뒤 글자가 맨 앞으로 온다
- 나머지 글자는 한 칸씩 오른쪽으로 간다

<span style="color:red">ex)</span> `"hello"` → 1번 밀기 → `"ohell"`

| 밀기 전 (A) | 인덱스 | 밀기 후 |
|-------------|--------|---------|
| h | 0 | 1번 칸 |
| e | 1 | 2번 칸 |
| l | 2 | 3번 칸 |
| l | 3 | 4번 칸 |
| o | 4 | 0번 칸 |

**1번 밀면 `A[0]`인 `h`는 1번 칸에 있다**

그래서 `A`를 `k`번 밀어서 `B`가 되려면,  
`B`에서 **`A[0]`이 있는 위치 = `k`** 라고 생각하였다

<br>

**2. `A[0]`이 `B`에서 몇 번째인지 찾는다**

`A`의 0번 글자가 `B`에서 몇 번째에 있는지 보면 밀기 횟수 후보가 나온다

<span style="color:red">ex)</span> `A = "hello"`, `B = "ohell"`

- `A[0]` = `'h'`
- `B`에서 `'h'`는 **1번** 인덱스
- → 1번 밀면 된다 ✅

<span style="color:red">ex)</span> `A = "abc"`, `B = "abc"`

- `A[0]` = `'a'`
- `B`에서 `'a'`는 **0번** 인덱스
- → 안 밀어도 됨 → `0` ✅

<br>

**3. 후보 `k`로 실제로 밀었을 때 `B`가 맞는지 확인한다**

위치만 보면 안 되는 경우도 있다

<span style="color:red">ex)</span> `A = "apple"`, `B = "elppa"`

- `A[0]` = `'a'` → `B`에서 **4번** 인덱스
- 4번 밀었다고 치면 → `"pleap"` ≠ `"elppa"` ❌
- → 불가능 → `-1`

그래서 `k`번 밀었을 때 정말 `B`가 되는지 **한 번 더 확인**해야 한다

```python
B == A[n-k:] + A[:n-k]
```

`A`를 오른쪽으로 `k`번 밀면 → 뒤 `k`글자 + 앞 `n-k`글자

<br>

**4. `A[0]`이 `B`에 여러 번 나오면 전부 확인한다**

<span style="color:red">ex)</span> `A = "atat"`, `B = "tata"`

- `A[0]` = `'a'` → `B`에서 1번, 3번에 있음
- `k = 1` → `"tata"` ✅ (최소값)
- `k = 3` → `"tata"` ✅ (이것도 되지만 1이 더 작음)

`A[0]` 위치를 하나만 보면 될 때도 있지만,  
여러 개면 **작은 `k`부터** 맞는지 확인하는 게 안전하다

---

## 오답노트

**1. `B`에서 `A[0]` 위치만 보고 끝내면 틀릴 수 있다**

`apple` / `elppa`처럼 첫 글자 위치는 맞아 보여도,  
나머지 글자 배열이 안 맞으면 `-1`이다

반드시 `A`를 `k`번 밀었을 때 `B`와 같은지 확인한다

<br>

**2. `A == B`면 밀기 전에 `0`을 반환한다**

`A[0]`이 `B`의 0번에 있어도, 그냥 같으면 밀기 `0`번이다

```python
if A == B:
    return 0
```

<br>

**3. 슬라이싱으로 밀기 결과를 만든다**

`k`번 오른쪽으로 밀기 = **뒤 `k`글자 + 앞 `n-k`글자**

```python
A[n-k:] + A[:n-k]
```

<span style="color:red">ex)</span> `A = "hello"`, `k = 1`

- `A[4:]` = `"o"`
- `A[:4]` = `"hell"`
- → `"ohell"` ✅

<br>

**4. `B.index(A[0])`만 쓰면 중복 글자에서 놓칠 수 있다**

`atat`처럼 `A[0]`이 여러 번 나오면,  
첫 번째 위치가 항상 정답은 아닐 수 있다 (이 문제에선 1번이 맞음)

`k`를 0부터 돌면서 `B[k] == A[0]`이고 밀기 결과가 `B`와 같을 때 `k`를 반환하면 된다

---

## 정답

```python
def solution(A, B):
    if A == B:
        return 0
    n = len(A)
    for k in range(n):
        if B[k] == A[0] and B == A[n-k:] + A[:n-k]:
            return k
    return -1
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `if A == B` | 안 밀어도 같으면 0 |
| `for k in range(n)` | 0 ~ n-1번 밀기 후보 |
| `B[k] == A[0]` | k번 밀면 A[0]이 k번 칸에 옴 |
| `A[n-k:] + A[:n-k]` | A를 오른쪽으로 k번 밀은 결과 |
| `return -1` | 어떤 k로도 B가 안 되면 불가능 |
