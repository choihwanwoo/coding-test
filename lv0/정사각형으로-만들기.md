# 코딩테스트 연습 - 정사각형으로 만들기 (LV.0)

## 풀이

**1. 행과 열 중 큰 값이 정사각형의 한 변 길이다.**

```python
rows = len(arr)
cols = len(arr[0])
size = max(rows, cols)
```

**2. 각 행의 부족한 열을 0으로 채운다.**

```python
row + [0] * (size - cols)
```

**3. 부족한 행도 0으로 만든다.**

```python
[[0] * size for _ in range(size - rows)]
```

리스트 컴프리헨션을 사용하면 각 0 행이 서로 다른 리스트로 만들어진다.

---

## 오답노트

```python
[[0] * size] * (size - rows)  # 주의
```

이 방식은 같은 리스트를 여러 번 참조한다. 나중에 한 행을 수정하면 다른 0 행도 함께 바뀔 수 있으므로, 행마다 새 리스트를 만드는 리스트 컴프리헨션을 사용한다.

---

## 정답

```python
def solution(arr):
    rows = len(arr)
    cols = len(arr[0])
    size = max(rows, cols)

    answer = [row + [0] * (size - cols) for row in arr]
    answer += [[0] * size for _ in range(size - rows)]

    return answer
```

### 한 줄 요약

> 큰 쪽 길이를 기준으로 부족한 열과 행을 0으로 채운다.
