# 코딩테스트 연습 - 정사각형으로 만들기 (LV.0)

## 풀이

**1. 행과 열 중 큰 수가 정사각형의 한 변 길이다.**

행이 더 많으면 행 수만큼 열을 만들고, 열이 더 많으면 열 수만큼 행을 만들어야 한다.

그래서 정사각형의 한 변 길이는 행 수와 열 수 중 큰 값이다.

```python
size = max(len(arr), len(arr[0]))
```

<span style="color:red">ex)</span>

- `4행 3열` → `4 × 4` 정사각형 필요
- `2행 4열` → `4 × 4` 정사각형 필요
- `2행 2열` → 이미 `2 × 2` 정사각형

<br>

**2. 각 행의 끝에 부족한 0을 채운다.**

현재 열 수가 `cols`이고 목표 길이가 `size`라면, 각 행에는 `size - cols`개의 `0`이 더 필요하다.

```python
row + [0] * (size - cols)
```

<span style="color:red">ex)</span> `4행 3열`일 때

```python
[572, 22, 37] + [0] * (4 - 3)
# [572, 22, 37, 0]
```

<br>

**3. 부족한 행도 0으로 채운다.**

현재 행 수가 `rows`라면 `size - rows`개의 행을 추가해야 한다.

새 행 하나는 열이 `size`개인 0 리스트다.

```python
[[0] * size for _ in range(size - rows)]
```

<span style="color:red">ex)</span> `2행 4열`일 때

```python
[[0] * 4 for _ in range(4 - 2)]
# [[0, 0, 0, 0], [0, 0, 0, 0]]
```

---

## 오답노트

**1. 행이 부족한 경우와 열이 부족한 경우를 하나만 처리하면 안 된다.**

```python
if rows > cols:
    # 열만 추가
```

행이 더 많은 경우에는 맞을 수 있지만, 열이 더 많은 경우에는 부족한 행을 추가하지 못한다.

`size = max(rows, cols)`를 정한 뒤, 행과 열을 모두 `size`에 맞추면 두 경우를 한 번에 처리할 수 있다.

<br>

**2. 같은 0 리스트를 여러 번 넣으면 안 된다.**

```python
result += [[0] * size] * (size - rows)  # 주의
```

이 방식은 같은 리스트 객체를 여러 번 참조하게 된다.

나중에 한 행의 값을 바꾸면 다른 0 행도 같이 바뀔 수 있다.

```python
[[0] * size for _ in range(size - rows)]  # ✅
```

리스트 컴프리헨션으로 만들면 행마다 서로 다른 리스트가 생성된다.

<br>

**3. 이미 정사각형인 경우에는 0을 추가하지 않는다.**

`rows == cols`라면 `size - rows`, `size - cols`가 모두 `0`이다.

`[0] * 0`은 빈 리스트이고 `range(0)`도 반복하지 않으므로, 같은 코드로 원본 모양이 유지된다.

---

## 정답

```python
def solution(arr):
    rows = len(arr)
    cols = len(arr[0])
    size = max(rows, cols)

    answer = [row + [0] * (size - cols) for row in arr]
    answer += [[0] * size for _ in range(size - rows)]

    return answer
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `rows = len(arr)` | 현재 행 수 |
| `cols = len(arr[0])` | 현재 열 수 |
| `size = max(rows, cols)` | 만들 정사각형의 한 변 길이 |
| `row + [0] * (size - cols)` | 각 행의 부족한 열을 0으로 채움 |
| `[[0] * size for _ in range(size - rows)]` | 부족한 행을 0으로 채움 |

### 한 줄 요약

> 행과 열 중 큰 길이를 기준으로 잡고, 모자라는 열과 행을 0으로 채우면 정사각형이 된다.
