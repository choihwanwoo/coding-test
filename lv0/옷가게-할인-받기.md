# 코딩테스트 연습 - 옷가게 할인 받기 (LV.0)

## 풀이

**1. 금액 구간마다 할인율이 다르다.**

| 금액 | 할인 |
|------|------|
| 10만 원 이상 | 5% (`* 0.95`) |
| 30만 원 이상 | 10% (`* 0.9`) |
| 50만 원 이상 | 20% (`* 0.8`) |
| 10만 원 미만 | 할인 없음 |

<span style="color:red">ex)</span>

- `150000` → `150000 * 0.95 = 142500`
- `580000` → `580000 * 0.8 = 464000`

<br>

**2. `if-else`로 구간을 나눈다.**

큰 금액부터 검사하거나, 작은 금액부터 `미만`으로 나눠도 된다.

중요한 건 **10만 원 미만은 할인 없이 그대로** 두는 것.

```java
if (price >= 500000) {
    answer = price * 0.8;
} else if (price >= 300000) {
    answer = price * 0.9;
} else if (price >= 100000) {
    answer = price * 0.95;
} else {
    answer = price;
}
```

<br>

**3. 계산은 `double`, 반환은 `int`다.**

할인율 곱하면 소수점이 나올 수 있어서 `double`로 계산한다.

하지만 메서드 반환 타입은 `int`라서, 마지막에 `(int)`로 바꾼다.

```java
return (int) answer;  // 소수점 버림
```

`public double solution`으로 바꾸면 안 된다. 문제에서 정한 형식을 유지해야 한다.

---

## 오답노트

**1. `double`을 그대로 `return`하려 했다.**

반환 타입이 `int`인데 `double`을 그대로 주면 에러다.

`return (int) answer;`로 맞춰야 한다.

<br>

**2. 이상/이하 연산자를 헷갈렸다.**

| 말 | 코드 |
|----|------|
| 이상 | `>=` |
| 이하 | `<=` |
| 초과 | `>` |
| 미만 | `<` |

이 문제는 **이상** 기준이라 `>=`를 쓴다.

<br>

**3. 10만 원 미만 처리를 빼먹어서 정확성 80점이 나왔다.**

처음에 이렇게 짰다.

```java
if (price < 300000) {
    answer = price * 0.95;
} else if (price < 500000) {
    answer = price * 0.9;
} else {
    answer = price * 0.8;
}
```

이러면 `300000` 미만은 **전부 5% 할인**이 적용된다.

10만 원 미만은 할인이 없어야 하는데 빠져서, 나머지 20점이 틀렸다.

`price < 100000`이면 `answer = price`인 분기를 넣으니까 100점이 됐다.

---

## 정답

```java
class Solution {
    public int solution(int price) {
        double answer = 0;

        if (price >= 500000) {
            answer = price * 0.8;
        } else if (price >= 300000) {
            answer = price * 0.9;
        } else if (price >= 100000) {
            answer = price * 0.95;
        } else {
            answer = price;
        }

        return (int) answer;
    }
}
```
