# 코딩테스트 연습 - [PCCE 기출문제] 1번. 문자 출력 (LV.0)

## 풀이

1. String message =`"___"`; → 빈 칸의 내용을 message로 입력 받는다.

그러므로 첫번째 빈 칸 안에는 `Let's go!`가 들어간다 생각하였다.

2. System.out.println("3 2 1"); → 3,2,1을 줄바꿈을 사용하여 출력한다.

그러므로 두번째, 세번째 빈 칸 안에는 `\n`이 들어간다 생각하였다.

---

## 정답

```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        String message = "Let's go!";

        System.out.println("3\n2\n1");
        System.out.println(message);
    }
}
```
