# 코딩테스트 연습 - 안전지대 (LV.0)

## 풀이

**1. 지뢰(`1`)와 그 주변 8칸은 위험 지역이다**

`board`는 `n × n` 판이다

- `1` → 지뢰
- `0` → 빈칸

지뢰가 있는 칸 + 上下左右 + 대각선 8칸이 모두 위험하다

위험하지 않은 칸 개수가 답이다

<span style="color:red">ex)</span>

- 지뢰 1개만 가운데 있으면, 그 주변 `3×3`이 위험
- 지뢰가 겹치면 위험 지역도 겹침 (두 번 빼면 안 됨)
- 전부 지뢰면 답은 `0`

<br>

**2. 주변 8칸은 좌표 이동으로 본다**

지금 지뢰 위치가 `(x, y)`면 주변은

| 방향 | x 변화 | y 변화 |
|------|--------|--------|
| 위 | -1 | 0 |
| 아래 | 1 | 0 |
| 왼쪽 | 0 | -1 |
| 오른쪽 | 0 | 1 |
| 왼쪽 위 | -1 | -1 |
| 오른쪽 위 | -1 | 1 |
| 왼쪽 아래 | 1 | -1 |
| 오른쪽 아래 | 1 | 1 |

코드로는 이렇게 둔다

```python
dx = [-1, -1, -1, 0, 0, 1, 1, 1]
dy = [-1, 0, 1, -1, 1, -1, 0, 1]
```

`nx = x + dx[i]`, `ny = y + dy[i]`가 주변 칸이다

<br>

**3. 판 밖으로 나가면 안 된다**

모서리에 지뢰가 있으면 주변 8칸 중 일부는 판 밖이다

그래서 표시하기 전에 검사한다

```python
if 0 <= nx < n and 0 <= ny < n:
```

범위 안일 때만 위험 표시를 한다

<br>

**4. 흐름**

1. 위험 표시용 판을 하나 만든다 (처음엔 전부 안전)
2. `board`를 돌면서 `1`인 칸을 찾는다
3. 그 칸과 주변 8칸을 위험으로 표시한다
4. 마지막에 위험 아닌 칸 개수를 센다

지뢰끼리 위험 지역이 겹쳐도,  
이미 위험인 칸을 다시 위험으로 표시하면 되므로 중복 걱정이 없다

---

## 오답노트

**1. 지뢰만 세고 주변을 빼먹으면 안 된다**

지뢰 칸만 위험인 게 아니다

주변 8칸도 전부 위험이다

<br>

**2. 위험 칸을 뺄 때 겹침을 조심해야 한다**

지뢰가 두 개면 위험 지역이 겹칠 수 있다

`전체 칸 - 지뢰주변9칸 - 지뢰주변9칸`처럼 빼면  
겹친 칸을 두 번 빼서 틀린다

그래서 **표시해 두고 마지막에 한 번만 세는** 방식이 안전하다

<br>

**3. 인덱스 범위**

`board[nx][ny]`를 쓰기 전에  
`0 <= nx < n`, `0 <= ny < n`인지 꼭 본다

아니면 판 밖 접근 에러가 난다

---

## 정답

```python
def solution(board):
    n = len(board)
    danger = [[0] * n for _ in range(n)]

    dx = [-1, -1, -1, 0, 0, 1, 1, 1]
    dy = [-1, 0, 1, -1, 1, -1, 0, 1]

    for x in range(n):
        for y in range(n):
            if board[x][y] == 1:
                danger[x][y] = 1
                for i in range(8):
                    nx = x + dx[i]
                    ny = y + dy[i]
                    if 0 <= nx < n and 0 <= ny < n:
                        danger[nx][ny] = 1

    answer = 0
    for x in range(n):
        for y in range(n):
            if danger[x][y] == 0:
                answer += 1

    return answer
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `n = len(board)` | 판 크기 |
| `danger = [[0] * n for _ in range(n)]` | 위험 표시판 (0=안전, 1=위험) |
| `board[x][y] == 1` | 지뢰 발견 |
| `danger[x][y] = 1` | 지뢰 칸도 위험 |
| `nx, ny` | 주변 칸 좌표 |
| `0 <= nx < n ...` | 판 안인지 확인 |
| `danger[nx][ny] = 1` | 주변도 위험 표시 |
| `danger[x][y] == 0` | 안전한 칸만 카운트 |
