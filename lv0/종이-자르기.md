# 코딩테스트 연습 - 종이 자르기 (LV.0)

## 풀이

**1. 잘라서 만들어야 하는 종이 조각은 총 `M × N`개다.**

`M × N` 크기의 종이를 `1 × 1` 크기로 모두 자르면, 가로로 `M`개 세로로 `N`개인 조각이 남는다.

```python
pieces = M * N
```

<span style="color:red">ex)</span>

- `M = 2`, `N = 2` → `1 × 1` 종이 `4개`
- `M = 2`, `N = 5` → `1 × 1` 종이 `10개`

<br>

**2. 한 번 자를 때마다 종이 조각은 정확히 1개 늘어난다.**

종이를 겹쳐서 자를 수 없으므로, 한 번의 자르기는 종이 조각 하나를 둘로 나누는 일이다.

즉, 자르기 전보다 조각 수가 항상 `1개` 늘어난다.

처음에는 종이가 `1개`이고, 최종적으로 `M × N`개가 되어야 한다.

```
필요한 자르기 횟수 = 최종 조각 수 - 처음 조각 수
                    = M × N - 1
```

<span style="color:red">ex)</span> `M = 2`, `N = 2`

```
처음       : 1개
1번 자른 뒤 : 2개
2번 자른 뒤 : 3개
3번 자른 뒤 : 4개
```

그래서 `2 × 2` 종이는 `4 - 1 = 3번` 잘라야 한다.

<br>

**3. 가로와 세로를 따로 계산해도 같은 결과가 나온다.**

먼저 가로로 `M`등분하려면 `M - 1`번 자른다.

그다음 가로 조각 `M개`를 각각 세로로 `N`등분해야 하므로, 세로 자르기는 `M × (N - 1)`번 필요하다.

```python
(M - 1) + M * (N - 1)
```

이를 정리하면 `M × N - 1`과 같다.

```python
(M - 1) + M * (N - 1)
= M - 1 + M * N - M
= M * N - 1
```

## 오답노트

**1. 가로와 세로 자르기 횟수만 더하면 부족하다.**

```python
M - 1 + N - 1  # ❌
```

`M = 2`, `N = 5`일 때 이 식은 `1 + 4 = 5`다.

하지만 가로로 한 번 자른 뒤에는 종이가 2조각이므로, 세로로 한 줄 자를 때도 **각 조각을 따로** 잘라야 한다.

실제 답은 `2 × 5 - 1 = 9`다.

<br>

**2. 겹쳐서 자르는 것으로 생각하면 안 된다.**

가로로 자른 2장을 포개고 세로로 4번 자르면 5번으로 끝날 것 같지만, 문제에서 종이를 겹쳐 자를 수 없다고 했다.

따라서 나뉜 종이를 각각 잘라야 한다.

<br>

**3. `M = 1`, `N = 1`도 확인한다.**

이미 `1 × 1` 크기라서 자를 필요가 없다.

```python
1 * 1 - 1  # 0
```

---

## 정답

```python
def solution(M, N):
    return M * N - 1
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `M * N` | 최종적으로 필요한 `1 × 1` 종이 조각 수 |
| `- 1` | 처음 종이 1장은 이미 있으므로 필요한 자르기 횟수 |

### 한 줄 요약

> 자를 때마다 종이 조각은 1개씩 늘어나므로, `M × N`개를 만들려면 `M × N - 1`번 자른다.
