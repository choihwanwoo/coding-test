# 코딩테스트 연습 - 중앙값 구하기 (LV.0)

## 풀이

**1. 중앙값은 “가운데 인덱스”가 아니라 “크기 순으로 가운데”다.**

그냥 `array[array.length / 2]`만 하면, 정렬이 안 된 상태의 중간 칸을 고르는 것이다.

문제에서 말하는 중앙값은 **값을 크기순으로 나열했을 때 한가운데**이므로, 먼저 정렬해야 한다고 생각하였다.

<span style="color:red">ex)</span> `array = [9, -1, 0]`

- 정렬 전 가운데 칸: `array[1] = -1` → 틀림
- 정렬 후 `[-1, 0, 9]` → 가운데는 `0` → 맞음

<br>

**2. `Arrays.sort`로 오름차순 정렬한다.**

```java
Arrays.sort(array);
```

작은 수 → 큰 수 순으로 다시 줄 세운다.

쓸 때 파일 위에 `import java.util.Arrays;`가 필요하다.

<br>

**3. 가운데 인덱스는 `array.length / 2`다.**

길이가 항상 홀수라서 가운데가 하나다.

인덱스는 0부터 시작하니까, 길이 5면 가운데는 2번째 칸 → `5 / 2 = 2`이다.

```java
int answer = array[array.length / 2];
```

<span style="color:red">ex)</span> `[1, 2, 7, 10, 11]`

- 길이 5 → `5 / 2 = 2`
- `array[2] = 7`

---

## 오답노트

**1. 정렬 없이 가운데 칸만 골랐다.**

`array`가 이미 정렬돼 있다고 착각하면 예제는 우연히 맞을 수 있다.

예1 `[1, 2, 7, 10, 11]`은 이미 정렬돼 있어서 통과해 보이지만,  
예2 `[9, -1, 0]`은 정렬 전이면 틀린다.

**무조건 정렬 먼저** 해야 한다.

<br>

**2. 중앙값을 평균으로 생각했다.**

중앙값(median) ≠ 평균(average).

평균은 다 더해서 개수로 나누는 것이고,  
중앙값은 **정렬 후 한가운데 값** 하나다.

<br>

**3. `Arrays.sort`를 몰라서 헤맸다.**

자바에서 배열 정렬은 직접 버블정렬을 짜도 되지만,  
입문 문제에서는 `Arrays.sort(array)`면 충분하다.

`import java.util.Arrays;`를 안 쓰면 에러가 난다.

---

## 정답

```java
import java.util.Arrays;

class Solution {
    public int solution(int[] array) {
        Arrays.sort(array);
        int answer = array[array.length / 2];
        return answer;
    }
}
```
