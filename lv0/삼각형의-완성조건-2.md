# 코딩테스트 연습 - 삼각형의 완성조건 (2) (LV.0)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/120868)

## 풀이

**1. 가장 긴 변은 나머지 두 변의 합보다 작아야 한다.**

주어진 두 변 중 짧은 변을 `a`, 긴 변을 `b`, 구할 변을 `x`라고 하자.

```python
a = min(sides)
b = max(sides)
```

`x`가 가장 긴 변인지에 따라 두 경우로 나눌 수 있다.

<br>

**2. 주어진 변 b가 가장 길다면 `b - a < x <= b`다.**

삼각형이 되려면 다음 조건이 필요하다.

```text
b < a + x
→ b - a < x
```

이 경우는 b가 가장 긴 변이므로 `x <= b`도 만족해야 한다.

따라서 가능한 정수는 `b - a + 1`부터 `b`까지다.

개수는 다음과 같다.

```text
b - (b - a + 1) + 1 = a
```

<span style="color:red">ex)</span> `sides = [3, 6]`

- `6 - 3 < x <= 6`
- 가능한 값 → `4, 5, 6`
- 개수 → `3`

<br>

**3. 새 변 x가 b보다 길다면 `b < x < a + b`다.**

x가 가장 긴 변이므로 두 변의 합보다 작아야 한다.

```text
b < x < a + b
```

가능한 정수는 `b + 1`부터 `a + b - 1`까지다.

개수는 다음과 같다.

```text
(a + b - 1) - (b + 1) + 1 = a - 1
```

<span style="color:red">ex)</span> `sides = [3, 6]`

- `6 < x < 9`
- 가능한 값 → `7, 8`
- 개수 → `2`

앞에서 `x == b`를 이미 포함했으므로 여기서는 `x > b`만 센다.

<br>

**4. 두 경우를 더하면 `2 * a - 1`이다.**

```text
a + (a - 1) = 2a - 1
```

결국 짧은 변의 길이만 알면 정답을 구할 수 있다.

```python
return 2 * min(sides) - 1
```

두 경우를 하나의 범위로 합쳐도 같은 결과다.

```text
b - a < x < a + b
```

양 끝을 제외한 정수의 개수는 `(a + b) - (b - a) - 1 = 2a - 1`이다.

<br>

**5. 예제에 적용해 본다.**

- `[1, 2]` → `1 < x < 3` → `2` 하나 → 결과 `1`
- `[3, 6]` → `3 < x < 9` → `4~8` → 결과 `5`
- `[11, 7]` → `4 < x < 18` → `5~17` → 결과 `13`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 두 변의 합과 같으면 삼각형이 되지 않는다.**

`3, 6, 9`는 `3 + 6 == 9`이므로 삼각형을 만들 수 없다.

가장 긴 변은 다른 두 변의 합보다 **엄격하게 작아야** 한다.

따라서 `x = a + b`는 포함하지 않는다.

<br>

**2. 두 변의 차와 같은 경우도 제외한다.**

`3, 6, 3` 역시 `3 + 3 == 6`이므로 삼각형이 되지 않는다.

따라서 `x = b - a`도 포함하지 않는다.

<br>

**3. 주어진 긴 변보다 큰 x도 가능하다.**

`[3, 6]`에서 `4, 5, 6`만 세면 `7, 8`을 놓친다.

새로 구하는 변이 가장 긴 변이 될 수도 있으므로 두 경우를 모두 포함해야 한다.

<br>

**4. 배열의 첫 번째 값이 짧은 변이라고 가정하면 안 된다.**

```python
sides = [11, 7]
```

위 예제의 짧은 변은 `7`이다. 입력 순서와 관계없이 `min(sides)`로 구해야 한다.

<br>

**5. 두 변이 같아도 같은 공식을 쓸 수 있다.**

`[3, 3]`이면 `0 < x < 6`이므로 가능한 값은 `1, 2, 3, 4, 5`다.

`2 * 3 - 1 = 5`로 그대로 계산된다.

---

## 정답

```python
def solution(sides):
    return 2 * min(sides) - 1
```

### 한 줄씩

- `min(sides)` → 주어진 두 변 중 짧은 변의 길이
- `2 * min(sides)` → 가능한 범위의 양 끝값 차이
- `- 1` → 양 끝값을 제외한 정수 개수로 계산
- `return` → 나머지 한 변이 될 수 있는 정수의 개수 반환

### 시간 복잡도

`sides`의 길이는 항상 2이므로 최솟값을 구하는 작업량이 일정하다.

따라서 **시간 복잡도와 추가 공간 복잡도는 모두 O(1)**이다.

### 한 줄 요약

> 나머지 변은 두 변의 차보다 크고 합보다 작아야 하므로, 가능한 정수 개수는 `2 * min(sides) - 1`이다.
