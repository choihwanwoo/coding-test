# 코딩테스트 연습 - 코드 처리하기 (LV.0)

## 풀이

**1. `mode`에 따라 짝수/홀수 인덱스 글자만 `ret`에 붙인다**

`code` 문자열을 처음부터 하나씩 보면서, 새 문자열 `ret`을 만든다

`mode`는 `0` 또는 `1`이고, 처음엔 `0`이다

<span style="color:red">ex)</span> `"abc1abc1abc"` → `"acbac"`

<br>

**2. `"1"`이 나오면 mode만 바꾼다**

`"1"`은 `ret`에 붙이지 않는다

스위치처럼 mode를 뒤집는다

- mode `0` → `1`
- mode `1` → `0`

```python
mode = 1 - mode
```

<br>

**3. mode가 0일 때는 짝수 인덱스만 붙인다**

`idx`가 `0, 2, 4, ...` 일 때만 `ret`에 더한다

`idx % 2 == 0`이면 짝수다

<span style="color:red">ex)</span> `"abc1..."`에서 mode 0일 때

| idx | 글자 | 짝수? | 붙임? |
|-----|------|-------|-------|
| 0 | a | O | a |
| 1 | b | X | |
| 2 | c | O | ac |

<br>

**4. mode가 1일 때는 홀수 인덱스만 붙인다**

`idx`가 `1, 3, 5, ...` 일 때만 붙인다

`idx % 2 == 1`이면 홀수다

<span style="color:red">ex)</span> `"abc1abc..."`에서 idx 3에서 mode가 1로 바뀐 뒤

| idx | 글자 | 홀수? | ret |
|-----|------|-------|-----|
| 4 | a | X | acb |
| 5 | b | O | acb |

<br>

**5. `ret`가 비어 있으면 `"EMPTY"`를 반환한다**

아무 글자도 못 붙였으면 빈 문자열 대신 `"EMPTY"`

```python
return ret if ret else 'EMPTY'
```

---

## 오답노트

**1. `"1"`을 글자로 붙이려고 했다**

`"1"`은 결과 문자열에 넣는 게 아니다

mode를 바꾸는 신호다

<br>

**2. 짝수/홀수를 헷갈렸다**

- mode `0` → **짝수** idx
- mode `1` → **홀수** idx

`idx % 2 == 0` → 짝수  
`idx % 2 == 1` → 홀수

<br>

**3. mode 바꿀 때 if-else를 길게 썼다**

```python
if mode == 0:
    mode = 1
else:
    mode = 0
```

이것도 되지만, `mode = 1 - mode`가 더 짧다

---

## 정답

```python
def solution(code):
    ret = ''
    mode = 0

    for idx in range(len(code)):
        if code[idx] == '1':
            mode = 1 - mode
        else:
            if mode == 0 and idx % 2 == 0:
                ret += code[idx]
            elif mode == 1 and idx % 2 == 1:
                ret += code[idx]

    return ret if ret else 'EMPTY'
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `ret = ''` | 결과 문자열 (처음엔 빈칸) |
| `mode = 0` | 처음 mode |
| `for idx in range(len(code))` | 0부터 끝까지 한 글자씩 |
| `code[idx] == '1'` | 1이면 mode만 전환 |
| `idx % 2 == 0` | 짝수 인덱스 |
| `idx % 2 == 1` | 홀수 인덱스 |
| `ret += code[idx]` | 글자 붙이기 |
| `ret if ret else 'EMPTY'` | 비었으면 EMPTY |
