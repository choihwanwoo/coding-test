# 코딩테스트 연습 - 로그인 성공? (LV.0)

## 풀이

**1. `db`를 돌면서 아이디부터 찾는다**

`id_pw`는 `[입력 아이디, 입력 비번]`이고  
`db`는 `[[아이디, 비번], ...]` 형태다

먼저 `db` 안에 **같은 아이디**가 있는지 보면 된다

- 아이디가 없으면 → `"fail"`
- 아이디는 있는데 비번이 다르면 → `"wrong pw"`
- 아이디·비번 둘 다 같으면 → `"login"`

이라고 생각하였다

<br>

**2. for문으로 `db`를 한 명씩 확인한다**

```python
user_id, user_pw = id_pw

for db_id, db_pw in db:
    if user_id == db_id:
        if user_pw == db_pw:
            return "login"
        else:
            return "wrong pw"
```

아이디가 같으면 그 자리에서 비번까지 비교하고  
바로 `return`하면 된다

아이디는 중복이 없다고 문제에 나와 있으니까  
한 번 찾으면 더 볼 필요 없다

<br>

**3. for를 다 돌았는데도 없으면 `"fail"`**

아이디가 `db`에 아예 없으면 for 안에서 `return`이 안 된다

그래서 마지막에

```python
return "fail"
```

을 두면 된다

<span style="color:red">ex)</span> `id_pw = ["meosseugi", "1234"]`

| db 아이디 | 비교 | 결과 |
|-----------|------|------|
| rardss | 다름 | 다음 |
| yyoom | 다름 | 다음 |
| meosseugi | 같음, 비번도 같음 | `"login"` |

<span style="color:red">ex)</span> `id_pw = ["programmer01", "15789"]`

- 아이디 `programmer01`은 있음
- 비번 `1145` ≠ `15789` → `"wrong pw"`

<span style="color:red">ex)</span> `id_pw = ["rabbit04", "98761"]`

- `rabbit04`가 db에 없음 → `"fail"`

---

## 오답노트

**1. 비번만 같다고 `"login"` 하면 안 된다**

<span style="color:red">ex)</span> 세 번째 예시에서 `jaja11`의 비번이 `98761`로 같다

하지만 입력 아이디는 `rabbit04`라서 다른 사람이다  
→ `"fail"`이 맞다

항상 **아이디 먼저**, 그다음 **비번** 순서로 본다

<br>

**2. 아이디가 있는데 비번이 틀리면 `"fail"`이 아니다**

`"fail"`은 **아이디 자체가 없을 때**다

아이디는 맞는데 비번만 틀리면 `"wrong pw"`다

<br>

**3. `db`를 다 안 보고 중간에 끊어도 된다**

아이디를 찾으면 그 자리에서 바로 `return`해도 된다

아이디가 유일하니까, 다른 사람을 더 볼 필요가 없다

---

## 정답

```python
def solution(id_pw, db):
    user_id, user_pw = id_pw
    for db_id, db_pw in db:
        if user_id == db_id:
            if user_pw == db_pw:
                return "login"
            else:
                return "wrong pw"
    return "fail"
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `user_id, user_pw = id_pw` | 입력 아이디·비번 꺼내기 |
| `for db_id, db_pw in db` | db 회원 한 명씩 확인 |
| `user_id == db_id` | 아이디가 같은지 |
| `user_pw == db_pw` | 비번도 같으면 login |
| `else: return "wrong pw"` | 아이디만 같고 비번 다름 |
| `return "fail"` | db에 아이디 없음 |
