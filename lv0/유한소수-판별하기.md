# 코딩테스트 연습 - 유한소수 판별하기 (LV.0)

## 풀이

**1. 기약분수로 만든 뒤, 분모만 보면 된다**

유한소수인지 보려면 `a/b`를 **기약분수**로 만든 다음  
분모의 소인수가 **2와 5만** 있는지 보면 된다고 문제에 나와 있다

기약분수는 분자·분모를 **최대공약수(gcd)** 로 나누면 된다  
저번에 분수의 덧셈에서 했던 약분이랑 같다

```python
import math

b //= math.gcd(a, b)
```

<span style="color:red">ex)</span> `a = 11`, `b = 22`

- `gcd(11, 22) = 11`
- 기약분수 → `1 / 2`
- 분모 `2` → 소인수 2만 → **유한소수** → `1`

<br>

**2. 분모에서 2와 5를 전부 나눠 본다**

기약분수의 분모 `b`에서

- `2`로 나눠떨어지는 동안 `2`로 나눈다
- `5`로 나눠떨어지는 동안 `5`로 나눈다

다 나눈 뒤 `b`가 `1`이면 → 소인수가 2, 5뿐이었다 → **유한소수 `1`**  
아니면 → 다른 소인수가 남아 있다 → **무한소수 `2`**

```python
while b % 2 == 0:
    b //= 2
while b % 5 == 0:
    b //= 5
```

<span style="color:red">ex)</span> `a = 7`, `b = 20`

- 이미 기약분수 (`gcd = 1`)
- `20 ÷ 2 = 10` → `10 ÷ 2 = 5` → `5 ÷ 5 = 1`
- 남는 값 `1` → 유한소수 → `1`

<span style="color:red">ex)</span> `a = 12`, `b = 21`

- `gcd(12, 21) = 3` → 기약분수 `4 / 7`
- `7`은 2로도 5로도 안 나눠짐 → 남는 값 `7`
- → 무한소수 → `2`

<br>

**3. 정수도 유한소수다**

분모가 `1`이면 (예: `2/1`) 정수인데,  
정수도 유한소수로 친다고 문제에 나와 있다

기약분수에서 분모가 `1`이면  
2·5로 나눌 것도 없고 바로 `1`이 남으니까 그대로 `1`을 반환하면 된다

## 오답노트

**1. 약분 없이 원래 분모만 보면 틀린다**

<span style="color:red">ex)</span> `11 / 22`

원래 분모 `22 = 2 × 11` → `11`이 있어서 무한소수처럼 보인다 ❌

하지만 기약분수 `1 / 2`로 만들면 분모는 `2`뿐 → 유한소수 ✅

그래서 **반드시 gcd로 약분한 뒤** 분모를 봐야 한다

<br>

**2. 분자 `a`는 약분할 때만 쓰고, 소인수 검사는 분모만 한다**

유한소수 조건은 **기약분수의 분모**에만 해당한다

분자를 2·5로 나누거나 할 필요는 없다

<br>

**3. `while`로 2와 5를 “전부” 나눠야 한다**

한 번만 `b //= 2` 하면 `20` → `10`에서 멈춘다

`10`에도 아직 `2`가 남아 있으니,  
`while b % 2 == 0`처럼 **더 이상 안 나눠질 때까지** 돌려야 한다

<br>

**4. Python은 `math.gcd`를 쓰면 된다**

자바에서는 `gcd` 메서드를 직접 만들었지만,  
파이썬은 `import math` 후 `math.gcd(a, b)`로 바로 쓸 수 있다

---

## 정답

```python
import math

def solution(a, b):
    b //= math.gcd(a, b)
    while b % 2 == 0:
        b //= 2
    while b % 5 == 0:
        b //= 5
    return 1 if b == 1 else 2
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `math.gcd(a, b)` | a와 b의 최대공약수 |
| `b //= math.gcd(a, b)` | 기약분수의 분모로 약분 |
| `while b % 2 == 0` | 2로 나눠떨어지는 동안 2 제거 |
| `while b % 5 == 0` | 5로 나눠떨어지는 동안 5 제거 |
| `return 1 if b == 1 else 2` | 1만 남으면 유한, 아니면 무한 |
