# 코딩테스트 연습 - 피자 나눠 먹기 (1) (LV.0)

## 풀이

**1. `n`을 7로 나눈 몫이 기본 피자 판 수다.**

피자 한 판이 7조각이니까, `n / 7`로 일단 몇 판이 필요한지 몫을 챙긴다.

<span style="color:red">ex)</span>

- `n = 7` → `1`
- `n = 1` → `1`
- `n = 15` → `3`

<br>

**2. 나머지가 있으면 피자를 1판 더한다.**

`N = n % 7`로 나머지를 구한다.

나머지가 있으면(`N >= 1`) `N`을 `1`로 바꾸고,  
없으면(`N == 0`) `N`을 `0`으로 둔다.

그다음 `answer = n / 7 + N`으로 리턴한다.

몫을 챙기고, 나머지가 있을 때만 1을 더해서 값을 받게 한 것이다.

```java
int N = n % 7;

if (N >= 1) {
    N = 1;
} else {
    N = 0;
}

answer = n / 7 + N;
```

<span style="color:red">ex)</span> `n = 15`

- `15 / 7 = 2` (몫)
- `15 % 7 = 1` → 나머지 있음 → `N = 1`
- `answer = 2 + 1 = 3`

## 오답노트

처음에 이렇게 했다.

```java
answer = n / 7 + n % 7;
```

이러면 나머지가 `1`일 때는 맞는데, `1`을 초과할 때는 무조건 틀렸다.

그래서 나머지가 `2~6`이면 무조건 `1`로 받게 `N`을 써서 조건문으로 바꿨다.

```java
int N = n % 7;

if (N >= 1) {
    N = 1;
} else {
    N = 0;
}

answer = n / 7 + N;
```

## 정답

```java
class Solution {
    public int solution(int n) {
        int answer = 0;
        int N = n % 7;

        if (N >= 1) {
            N = 1;
        } else {
            N = 0;
        }

        answer = n / 7 + N;

        return answer;
    }
}
```
