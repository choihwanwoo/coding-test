# 코딩테스트 연습 - 피자 나눠 먹기 (2) (LV.0)

## 풀이

**1. 피자 한 판은 6조각이고, 남김없이 똑같이 나눠야 한다.**

사람 `n`명이 조각을 똑같이 나눠 먹고, 남은 조각이 없어야 한다.

필요한 **최소 피자 판 수**를 구하면 된다.

<span style="color:red">ex)</span>

- `n = 6` → `1`
- `n = 10` → `5`
- `n = 4` → `2`

<br>

**2. 최소공배수(LCM)를 이용한다.**

전체 조각 수는 6의 배수여야 하고, 사람 수 `n`으로도 나눠떨어져야 한다.

그래서 `n`과 `6`의 **최소공배수**가 필요한 최소 조각 수다.

```java
int lcm = (n * 6) / gcd(n, 6);
```

피자 판 수는 그걸 6으로 나눈 값이다.

```java
answer = lcm / 6;
```

<span style="color:red">ex)</span> `n = 10`

- `gcd(10, 6) = 2`
- `lcm = (10 * 6) / 2 = 30`
- `answer = 30 / 6 = 5`

<br>

**3. gcd는 유클리드 호제법으로 구한다.**

`gcd`를 호출만 하고 정의를 안 하면 `cannot find symbol` 에러가 난다.

같은 클래스 안에 메서드를 따로 둔다.

```java
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

- `!=` → **같지 않다**
- `while (b != 0)` → `b`가 0이 될 때까지 반복
- `r = a % b` → 나머지
- `a = b`, `b = r` → 자리를 바꿔가며 반복
- `b == 0`이 되면 그때의 `a`가 최대공약수

<span style="color:red">ex)</span> `gcd(12, 8)`

- `12 % 8 = 4` → a=8, b=4
- `8 % 4 = 0` → a=4, b=0
- 결과: `4`

---

## 오답노트

**1. `gcd`를 호출만 하고 정의를 안 했다.**

```java
int lcm = (n * 6) / gcd(n, 6);  // gcd가 없어서 실행 안 됨
```

`solution` 메서드 밖, `Solution` 클래스 안에 `gcd`를 추가해야 한다.

<br>

**2. `!=` 의미를 헷갈렸다.**

`!=`는 **같지 않다**는 뜻이다.

`while (b != 0)`은 `b`가 0이 아닌 동안 돌리고, 0이 되면 멈춘다.

---

## 정답

```java
class Solution {
    public int solution(int n) {
        int answer = 0;

        int lcm = (n * 6) / gcd(n, 6);
        answer = lcm / 6;

        return answer;
    }

    int gcd(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
}
```
