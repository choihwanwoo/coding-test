# 코딩테스트 연습 - 직사각형 넓이 구하기 (LV.0)

## 풀이

**1. 가로는 x 차이, 세로는 y 차이로 구한다**

직사각형이 x축·y축에 평행하니까  
가로는 **x 좌표 차이**, 세로는 **y 좌표 차이**다

넓이는 `가로 × 세로`라고 생각하였다

<span style="color:red">ex)</span> `[[1, 1], [2, 1], [2, 2], [1, 2]]`

- 가로: `2 - 1 = 1`
- 세로: `2 - 1 = 1`
- 넓이: `1 × 1 = 1`

<br>

**2. `(x2 - x1) * (y3 - y2)`처럼 “인덱스 번호”에 의존하면 위험하다**

점이 항상 `dots[0]`, `dots[1]`, `dots[2]` 순서로  
왼쪽 아래 → 오른쪽 아래 → 오른쪽 위 이렇게 오라는 보장이 없다

<span style="color:red">ex)</span> `[[-1, -1], [1, 1], [1, -1], [-1, 1]]`

- `x2 - x1` = `1 - (-1)` = `2` → 가로는 우연히 맞음
- `y3 - y2` = `-1 - 1` = `-2` → 음수가 나옴

그래서 점 순서를 가정하지 말고,  
**가장 큰 x − 가장 작은 x**, **가장 큰 y − 가장 작은 y**로 구하는 게 안전하다

<br>

**3. 모든 x, y에서 최댓값·최솟값을 구한다**

```python
xs = [x for x, y in dots]
ys = [y for x, y in dots]

width = max(xs) - min(xs)
height = max(ys) - min(ys)
```

축에 평행한 직사각형이라 x는 두 종류, y도 두 종류뿐이다  
그래서 max − min이 곧 가로·세로가 된다

<span style="color:red">ex)</span> 두 번째 예시

- x: `-1, 1, 1, -1` → max `1`, min `-1` → 가로 `2`
- y: `-1, 1, -1, 1` → max `1`, min `-1` → 세로 `2`
- 넓이: `2 × 2 = 4`

---

## 오답노트

**1. 점 순서를 고정해서 `(x2-x1)*(y3-y2)`만 쓰면 틀릴 수 있다**

입출력 예시에선 우연히 맞을 수도 있지만,  
다른 순서로 점이 들어오면 다른 변을 빼게 된다

순서가 보장되지 않으니 **max / min**으로 구하는 편이 안전하다

<br>

**2. 음수 좌표가 있어도 max − min이면 양수가 나온다**

`1 - (-1) = 2`처럼,  
음수를 직접 빼도 가로·세로는 양수로 나온다

따로 `abs`를 안 써도 된다 (max가 항상 min 이상이라서)

<br>

**3. 네 점의 x가 전부 다르다고 생각하면 안 된다**

축에 평행한 직사각형이라  
x는 왼쪽/오른쪽 두 값, y는 아래/위 두 값만 있다

그래서 `max(xs) - min(xs)` 한 번이면 충분하다

---

## 정답

```python
def solution(dots):
    xs = [x for x, y in dots]
    ys = [y for x, y in dots]
    return (max(xs) - min(xs)) * (max(ys) - min(ys))
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `xs = [x for x, y in dots]` | 네 점의 x만 모음 |
| `ys = [y for x, y in dots]` | 네 점의 y만 모음 |
| `max(xs) - min(xs)` | 가로 길이 |
| `max(ys) - min(ys)` | 세로 길이 |
| `return 가로 * 세로` | 직사각형 넓이 |
