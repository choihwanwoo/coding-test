# 코딩테스트 연습 - 그림 확대 (LV.0)

## 풀이

**1. 그림의 각 문자를 가로로 `k`배 늘린다.**

`picture`의 한 줄은 `"."`과 `"x"`로 이루어진 문자열이다.

각 문자를 `k`번 반복해서 붙이면 가로 길이가 `k`배가 된다.

```python
expanded = ''.join(ch * k for ch in row)
```

<span style="color:red">ex)</span>

`row = ".x"`이고 `k = 3`이라면

```python
"." * 3  # "..."
"x" * 3  # "xxx"

# 합치면
"...xxx"
```

즉, 문자열 전체를 반복하는 것이 아니라 **문자 하나하나를 `k`번씩 반복**해야 한다.

<br>

**2. 가로로 확대한 한 줄을 세로로도 `k`번 넣는다.**

문제에서는 원래 그림의 한 픽셀이 가로와 세로 모두 `k`배 커져야 한다.

따라서 가로로 확대한 문자열을 결과 배열에 `k`번 추가한다.

```python
for _ in range(k):
    answer.append(expanded)
```

<span style="color:red">ex)</span> `".x"`를 `k = 3`배 확대하면

```python
"...xxx"
"...xxx"
"...xxx"
```

가로로 3배, 세로로도 3배가 되어 각 픽셀이 `3 × 3` 크기로 확대된다.

<br>

**3. 모든 행에 같은 작업을 반복한다.**

`picture`의 각 문자열을 하나씩 꺼내서

1. 각 문자를 `k`번 반복해 가로로 확대하고
2. 만들어진 문자열을 `k`번 추가하면 된다.

```python
for row in picture:
    expanded = ''.join(ch * k for ch in row)

    for _ in range(k):
        answer.append(expanded)
```

## 오답노트

**1. 문자열 전체를 `k`번 반복하면 안 된다.**

문자열 전체에 `* k`를 사용하면 각 픽셀이 커지는 것이 아니라, 원래 문자열 자체가 `k`번 반복된다.

<span style="color:red">ex)</span> `row = ".x"`, `k = 3`인 경우

```python
row * k
# ".x.x.x"
```

문제에서 원하는 것은 `"."`과 `"x"` 각각의 크기를 `k`배 확대하는 것이다.

따라서 `".x"`를 3배 확대하면 `"..."`과 `"xxx"`가 이어진 형태인 `"...xxx"`가 되어야 한다.

이를 위해 문자열 전체에 `* k`를 적용하는 것이 아니라, **각 문자에 `* k`를 적용한 뒤 하나의 문자열로 합쳐야 한다.**

```python
''.join(ch * k for ch in row)
# "...xxx"
```

<br>

**2. 가로만 확대하면 안 된다.**

```python
answer.append(''.join(ch * k for ch in row))
```

이렇게 한 번만 추가하면 가로 크기만 `k`배가 되고 세로 크기는 그대로다.

확대한 한 행을 다시 `k`번 추가해야 세로도 `k`배가 된다.

<br>

**3. `join()`을 사용하면 반복한 문자들을 하나의 문자열로 만들 수 있다.**

```python
[ch * k for ch in row]
```

의 결과는 문자열이 아니라 리스트다.

<span style="color:red">ex)</span>

```python
row = ".x"
k = 3

[ch * k for ch in row]
# ["...", "xxx"]
```

문제의 반환값은 문자열 배열이어야 하므로 `join()`으로 합친다.

```python
''.join(ch * k for ch in row)
# "...xxx"
```

## 정답

```python
def solution(picture, k):
    answer = []

    for row in picture:
        expanded = ''.join(ch * k for ch in row)

        for _ in range(k):
            answer.append(expanded)

    return answer
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `answer = []` | 확대된 그림을 저장할 배열 |
| `for row in picture:` | 그림을 한 행씩 확인 |
| `ch * k` | 한 픽셀을 가로로 `k`배 확대 |
| `''.join(ch * k for ch in row)` | 한 행 전체를 가로로 확대 |
| `for _ in range(k):` | 확대된 행을 세로로 `k`번 반복 |
| `answer.append(expanded)` | 결과 배열에 확대된 행 추가 |

### 한 줄 요약

> 각 문자를 `k`번 반복해서 가로로 확대하고, 그렇게 만든 행을 `k`번 반복해서 세로로 확대하면 된다.
