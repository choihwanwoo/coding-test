# 코딩테스트 연습 - 외계어 사전 (LV.0)

## 풀이

**1. `spell`의 알파벳을 모두 한 번씩 사용해야 한다.**

포함 여부만 확인하면 안 되고, 빠진 글자나 중복 글자도 없어야 한다.

**2. 정렬 결과를 비교한다.**

같은 알파벳을 같은 횟수만큼 사용했다면 정렬한 결과가 같다.

```python
sorted(["p", "o", "s"]) == sorted("sop")
```

사전의 단어 중 정렬 결과가 같은 것이 있으면 `1`, 없으면 `2`를 반환한다.

---

## 오답노트

```python
all(char in word for char in spell)  # ❌
```

이 방법은 `spell = ["p", "o", "s"]`, `word = "soop"`처럼 중복된 글자를 잡지 못한다. `set`도 중복을 없애므로 같은 이유로 적절하지 않다.

---

## 정답

```python
def solution(spell, dic):
    target = sorted(spell)

    for word in dic:
        if sorted(word) == target:
            return 1

    return 2
```

### 한 줄 요약

> `spell`과 단어를 정렬한 결과가 같으면 모든 알파벳을 한 번씩 사용한 단어다.
