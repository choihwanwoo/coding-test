# 코딩테스트 연습 - 외계어 사전 (LV.0)

## 풀이

**1. `spell`의 알파벳을 모두 한 번씩 사용해야 한다.**

단어에 `spell`의 알파벳이 포함되기만 하면 되는 문제가 아니다.

`spell`에 있는 알파벳을 **빠짐없이**, 그리고 **한 번씩만** 사용해서 만든 단어여야 한다.

<span style="color:red">ex)</span> `spell = ["p", "o", "s"]`

- `"sop"` → `p`, `o`, `s`를 각각 한 번씩 사용 → 가능
- `"soop"` → `o`를 두 번 사용 → 불가능
- `"so"` → `p`가 없음 → 불가능
- `"soda"` → `p`가 없고 다른 글자도 있음 → 불가능

<br>

**2. 글자를 정렬하면 순서와 상관없이 비교할 수 있다.**

같은 알파벳을 같은 횟수만큼 사용했다면, 정렬한 결과가 같다.

```python
sorted(["p", "o", "s"])  # ['o', 'p', 's']
sorted("sop")              # ['o', 'p', 's']
```

그래서 `spell`을 정렬한 결과와 `dic`의 각 단어를 정렬한 결과가 같으면, 만들 수 있는 단어다.

<br>

**3. 같은 단어가 하나라도 있으면 `1`을 반환한다.**

`dic`을 하나씩 돌면서 정렬 결과를 비교한다.

같은 결과를 찾으면 바로 `1`을 반환하고, 끝까지 못 찾으면 `2`를 반환한다.

```python
target = sorted(spell)

for word in dic:
    if sorted(word) == target:
        return 1

return 2
```

문제에서 만들 수 있는 단어는 `dic`에 두 개 이상 존재하지 않는다고 했지만, 하나를 찾는 즉시 반환해도 된다.

---

## 오답노트

**1. `in`으로 글자가 포함됐는지만 확인하면 안 된다.**

```python
if all(char in word for char in spell):  # ❌
```

이 방식은 `spell = ["p", "o", "s"]`, `word = "soop"`일 때도 `True`가 된다.

하지만 `"soop"`에는 `p`가 없고 `o`가 두 번 있으므로 만들 수 없는 단어다.

글자 종류뿐 아니라 **글자 개수**까지 같아야 하므로 정렬해서 비교한다.

<br>

**2. 길이만 같다고 같은 단어가 아니다.**

```python
if len(word) == len(spell):  # ❌
```

길이가 같아도 들어 있는 알파벳이 다를 수 있다.

<span style="color:red">ex)</span> `spell = ["p", "o", "s"]`, `word = "sad"`

둘 다 길이는 `3`이지만 `p`, `o` 대신 `a`, `d`가 있으므로 불가능하다.

<br>

**3. `set`으로 비교하면 중복 글자를 놓칠 수 있다.**

```python
set(word) == set(spell)  # ❌
```

`set`은 같은 값을 하나만 남긴다.

그래서 `"soop"`도 `{'s', 'o', 'p'}`처럼 보일 수 있어, 글자 수가 다른 문제를 정확히 판단할 수 없다.

---

## 정답

```python
def solution(spell, dic):
    target = sorted(spell)

    for word in dic:
        if sorted(word) == target:
            return 1

    return 2
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `sorted(spell)` | 필요한 알파벳을 정렬한 기준값 |
| `for word in dic` | 사전의 단어를 하나씩 확인 |
| `sorted(word)` | 단어의 글자와 개수를 정렬 결과로 표현 |
| `== target` | 필요한 알파벳을 모두 한 번씩 썼는지 확인 |
| `return 1` | 만들 수 있는 단어를 찾음 |
| `return 2` | 끝까지 찾지 못함 |

### 한 줄 요약

> `spell`과 단어를 정렬한 결과가 같으면, 같은 알파벳을 한 번씩 사용한 단어다.
