# 코딩테스트 연습 - 마지막 두 원소 (LV.0)

## 풀이

**1. 리스트의 마지막 두 원소를 꺼낸다.**

Python에서는 음수 인덱스를 쓰면 리스트의 뒤에서부터 원소를 가져올 수 있다.

```python
last = num_list[-1]
prev = num_list[-2]
```

- `num_list[-1]` → 마지막 원소
- `num_list[-2]` → 마지막 바로 앞 원소

리스트 길이가 최소 `2`이므로 두 원소를 모두 가져올 수 있다.

<span style="color:red">ex)</span> `num_list = [2, 1, 6]`

- `last = 6`
- `prev = 1`

<br>

**2. 마지막 원소가 더 크면 두 원소의 차를 구한다.**

```python
if last > prev:
    value = last - prev
```

마지막 원소에서 그 전 원소를 빼면 된다.

<span style="color:red">ex)</span> `[2, 1, 6]`

`6 > 1`이므로 `6 - 1 = 5`를 추가한다.

결과는 `[2, 1, 6, 5]`다.

<br>

**3. 마지막 원소가 크지 않으면 마지막 원소의 두 배를 구한다.**

```python
else:
    value = last * 2
```

**작거나 같은 경우**는 모두 `else`에서 처리한다.

<span style="color:red">ex)</span> `[5, 2, 1, 7, 5]`

`5`가 `7`보다 크지 않으므로 `5 * 2 = 10`을 추가한다.

결과는 `[5, 2, 1, 7, 5, 10]`이다.

<br>

**4. 기존 리스트 뒤에 새 값 하나를 붙여서 반환한다.**

```python
return num_list + [value]
```

`[value]`는 새 값 하나가 들어 있는 리스트다.

리스트끼리 `+`로 이어 붙이면 기존 원소들의 순서를 유지하면서 맨 뒤에 새 값이 추가된다.

---

## 오답노트

**1. `[-1]`과 `[-2]`를 반대로 쓰면 안 된다.**

빼는 순서는 **마지막 원소 - 그 전 원소**다.

```python
last - prev  # 6 - 1 = 5 ✅
prev - last  # 1 - 6 = -5 ❌
```

<br>

**2. 두 원소가 같을 때도 두 배를 추가해야 한다.**

조건은 마지막 원소가 그 전 원소보다 **큰 경우**다.

`>=`를 쓰면 같은 경우에 차이인 `0`을 추가하게 된다.

<span style="color:red">ex)</span> `[3, 3]`

- `3 > 3`은 거짓
- 마지막 원소의 두 배인 `6`을 추가
- 결과: `[3, 3, 6]`

<br>

**3. 리스트에 숫자를 바로 더할 수는 없다.**

```python
num_list + value    # 리스트 + 정수라서 오류 ❌
num_list + [value]  # 리스트끼리 이어 붙이기 ✅
```

새 값을 대괄호로 감싸서 리스트로 만든 뒤 더해야 한다.

또는 `num_list.append(value)`로 추가한 다음 `num_list`를 반환해도 된다.

다만 `append()` 자체의 반환값은 `None`이므로 `return num_list.append(value)`라고 쓰면 안 된다.

---

## 정답

```python
def solution(num_list):
    last = num_list[-1]
    prev = num_list[-2]

    if last > prev:
        value = last - prev
    else:
        value = last * 2

    return num_list + [value]
```

### 한 줄씩

- `last = num_list[-1]` → 마지막 원소 저장
- `prev = num_list[-2]` → 마지막 바로 앞 원소 저장
- `if last > prev:` → 마지막 원소가 더 큰지 비교
- `value = last - prev` → 더 크면 두 원소의 차를 저장
- `value = last * 2` → 작거나 같으면 마지막 원소의 두 배를 저장
- `return num_list + [value]` → 기존 리스트 끝에 새 값 하나를 붙여 반환

### 한 줄 요약

> 마지막 원소가 그 전 원소보다 크면 차를, 작거나 같으면 마지막 원소의 두 배를 리스트 끝에 추가한다.
