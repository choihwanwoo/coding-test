# 코딩테스트 연습 - 전국 대회 선발 고사 (LV.0)

## 풀이

**1. 학생 번호는 배열의 인덱스다.**

`rank[i]`와 `attendance[i]`는 모두 `i번 학생`의 정보다.

그래서 학생 번호는 따로 찾을 필요 없이 인덱스 `i`를 쓰면 된다.

<span style="color:red">ex)</span>

```python
rank = [3, 7, 2, 5, 4, 6, 1]
```

- `rank[0] = 3` → 0번 학생은 3등
- `rank[2] = 2` → 2번 학생은 2등
- `rank[6] = 1` → 6번 학생은 1등

<br>

**2. 참석 가능한 학생만 골라낸다.**

전국 대회에 참석할 수 있는 학생은 `attendance[i]`가 `True`인 학생이다.

`enumerate`를 사용하면 학생 번호 `i`와 참석 여부를 같이 꺼낼 수 있다.

```python
students = [i for i, can_attend in enumerate(attendance) if can_attend]
```

<span style="color:red">ex)</span>

```python
attendance = [False, True, True, True, True, False, False]
```

참석 가능한 학생 번호는 `[1, 2, 3, 4]`다.

<br>

**3. `rank`가 작은 순서대로 정렬한다.**

등수는 `1등`이 가장 높고 숫자가 작을수록 좋다.

따라서 참석 가능한 학생 번호를 `rank[i]` 기준으로 오름차순 정렬하면 된다.

```python
students.sort(key=lambda i: rank[i])
```

<span style="color:red">ex)</span>

| 학생 번호 | 등수 |
|------|------|
| 1 | 7 |
| 2 | 2 |
| 3 | 5 |
| 4 | 4 |

등수 순으로 정렬하면 학생 번호는 `[2, 4, 3, 1]`이 된다.

앞의 세 명 `a, b, c`은 각각 `2`, `4`, `3`이다.

<br>

**4. 문제에서 요구한 식으로 반환한다.**

선발된 세 학생 번호가 `a`, `b`, `c`일 때 반환값은 다음과 같다.

```python
10000 * a + 100 * b + c
```

```python
10000 * 2 + 100 * 4 + 3  # 20403
```

## 오답노트

**1. `rank`가 큰 순서로 정렬하면 안 된다.**

```python
students.sort(key=lambda i: rank[i], reverse=True)  # ❌
```

`rank`는 점수가 아니라 **등수**다.

등수 `1`이 가장 높고 `7`이 가장 낮으므로, `reverse=True`를 쓰면 낮은 등수부터 뽑게 된다.

<br>

**2. 참석 여부가 아니라 학생 번호를 정렬 기준으로 쓰면 안 된다.**

```python
students = sorted(i for i, can_attend in enumerate(attendance) if can_attend)  # ❌
```

이 코드는 학생 번호가 작은 순서로 정렬한다.

문제는 학생 번호가 아니라 **등수가 높은 순서**로 세 명을 뽑아야 하므로 `key=lambda i: rank[i]`가 필요하다.

<br>

**3. `a`, `b`, `c`은 1부터 세는 번호가 아니다.**

학생 번호는 `0번`부터 시작한다.

그래서 인덱스에 `+1`을 하면 반환값이 틀린다.

<span style="color:red">ex)</span> 첫 번째 예시의 1등은 배열 인덱스 `6`인 6번 학생이다.

---

## 정답

```python
def solution(rank, attendance):
    students = [i for i, can_attend in enumerate(attendance) if can_attend]
    students.sort(key=lambda i: rank[i])

    a, b, c = students[:3]
    return 10000 * a + 100 * b + c
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `enumerate(attendance)` | 학생 번호와 참석 여부를 함께 꺼냄 |
| `if can_attend` | 참석 가능한 학생만 남김 |
| `key=lambda i: rank[i]` | 학생 번호 `i`의 등수를 정렬 기준으로 사용 |
| `students[:3]` | 등수가 가장 높은 세 학생 |
| `10000 * a + 100 * b + c` | 문제에서 요구한 반환값 계산 |

### 한 줄 요약

> 참석 가능한 학생의 번호를 `rank`가 작은 순으로 정렬한 뒤, 앞의 세 명으로 값을 만든다.
