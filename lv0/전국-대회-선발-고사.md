# 코딩테스트 연습 - 전국 대회 선발 고사 (LV.0)

## 풀이

**1. 학생 번호는 배열의 인덱스다.**

`rank[i]`, `attendance[i]`는 `i번 학생`의 정보다. 참석 가능한 학생 번호만 먼저 골라낸다.

```python
students = [i for i, can_attend in enumerate(attendance) if can_attend]
```

**2. `rank`가 작은 순서로 정렬한다.**

등수는 숫자가 작을수록 높다. 따라서 학생 번호를 `rank[i]` 기준으로 오름차순 정렬하면 선발 순서가 된다.

```python
students.sort(key=lambda i: rank[i])
```

**3. 앞의 세 학생으로 반환값을 만든다.**

```python
a, b, c = students[:3]
return 10000 * a + 100 * b + c
```

---

## 오답노트

`reverse=True`를 쓰면 등수 숫자가 큰 학생부터 정렬된다. `rank`는 점수가 아니라 등수이므로 오름차순으로 정렬해야 한다.

---

## 정답

```python
def solution(rank, attendance):
    students = [i for i, can_attend in enumerate(attendance) if can_attend]
    students.sort(key=lambda i: rank[i])

    a, b, c = students[:3]
    return 10000 * a + 100 * b + c
```

### 한 줄 요약

> 참석 가능한 학생만 `rank` 오름차순으로 정렬해 앞의 세 명을 고른다.
