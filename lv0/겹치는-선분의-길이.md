# 코딩테스트 연습 - 겹치는 선분의 길이 (LV.0)

## 풀이

**1. 선분 3개 중, 2개 이상 겹치는 구간의 길이를 구한다**

입력이 `[[0, 2], [-3, -1], [-2, 1]]`처럼 선분 3개다

한 점만 닿는 건 길이 0이다

<span style="color:red">ex)</span>

- `[[0, 1], [2, 5], [3, 9]]` → `2`
- `[[-1, 1], [1, 3], [3, 9]]` → `0`
- `[[0, 5], [3, 9], [1, 10]]` → `8`

<br>

**2. 왜 이런 코드가 나왔는지, 처음부터 따라가 보기**

다른 선분끼리 start/end를 비교해도 되지만, 선분이 3개면 쌍마다 겹침을 구한 뒤 합치는 게 헷하다

그래서 생각을 바꿨다

> 숫자 선을 1칸짜리로 쪼개고,  
> 각 칸을 선분이 몇 개나 지나가는지 센다  
> 2개 이상이면 그 칸은 겹친 구간이다

<br>

**2-1. 길이는 “점”이 아니라 “칸”이다**

`[0, 2]`를 점 `0, 1, 2`로 보면 헷갈린다

길이는 이렇게 칸으로 본다

```
0 ----1---- 2
  칸A   칸B
```

- 칸A: `0 → 1`
- 칸B: `1 → 2`
- 길이 = 칸 2개 = `2`

그래서 코드에서 `range(start, end)`를 쓴다  
`start`부터 `end` **직전**까지 = 덮는 칸들

`[0, 2]` → `i = 0, 1`  
점이 아니라 **칸 번호**라고 보면 된다

한 점만 닿는 `[-1, 1]`과 `[1, 3]`은  
공통 칸이 없어서 길이가 0이 된다

<br>

**2-2. `count = [0] * 201`은 뭔가**

숫자 선 `-100`부터 `100`까지를 칸으로 보면 칸이 최대 200개다

파이썬 리스트는 인덱스가 `0`부터라서,  
음수 좌표를 그대로 `count[-3]`처럼 쓰기 어렵다

그래서 자리를 `201`칸 만들어 두고, 좌표에 `100`을 더해 옮긴다

| 실제 좌표(칸 시작) | 리스트 인덱스 |
|--------------------|---------------|
| `-100` | `0` |
| `-1` | `99` |
| `0` | `100` |
| `1` | `101` |
| `100` | `200` |

`count[i + 100]`의 `+100`이 그 이동이다

처음엔 전부 `0` = 아직 아무 선분도 안 지남

<br>

**2-3. 선분마다 지나가는 칸에 +1 한다**

```python
for start, end in lines:
    for i in range(start, end):
        count[i + 100] += 1
```

`for start, end in lines:`  
→ 선분 3개를 하나씩 꺼냄  
예: `start=0`, `end=2`

`for i in range(start, end):`  
→ 그 선분이 덮는 칸 `i`를 하나씩 봄

`count[i + 100] += 1`  
→ 그 칸을 지나는 선분 개수를 1 늘림

<span style="color:red">ex)</span> `lines = [[0, 2], [-3, -1], [-2, 1]]`

1) `[0, 2]` → 칸 `0`, `1`에 +1  
2) `[-3, -1]` → 칸 `-3`, `-2`에 +1  
3) `[-2, 1]` → 칸 `-2`, `-1`, `0`에 +1

겹친 칸만 보면

| 칸 | 몇 개가 지나나 |
|----|----------------|
| `-2` | 2 (`[-3,-1]`, `[-2,1]`) |
| `0` | 2 (`[0,2]`, `[-2,1]`) |

나머지 칸은 1개 이하

<br>

**2-4. 마지막에 2 이상인 칸만 센다**

```python
answer = 0
for c in count:
    if c >= 2:
        answer += 1
```

`c`는 그 칸을 지나는 선분 수다

- `c == 0` → 아무도 안 지남
- `c == 1` → 선분 하나만 있음 (겹침 아님)
- `c >= 2` → 두 개 이상 겹침 → 길이 1 추가

위에서 칸 `-2`, `0` 두 칸이니까 `answer = 2`

<br>

**2-5. 한 줄로 정리**

1. 숫자 선을 1짜리 칸으로 나눈다  
2. 각 선분이 지나는 칸에 표시(+1)한다  
3. 표시가 2 이상인 칸 개수가 답이다  

그래서 저 코드가 나온 것이다

## 오답노트

**1. 처음에 `lines.end`처럼 썼다**

```python
if lines.end < lines.start:
```

`lines`는 객체가 아니라 리스트다

```python
lines[0]      # [0, 2]
lines[0][0]   # 시작
lines[0][1]   # 끝
```

그래서 `AttributeError: 'list' object has no attribute 'end'`가 났다

<br>

**2. 다른 선분의 start, end를 비교해서 겹치는 길이를 구하려고 했다**

같은 선분 안의 start/end가 아니라, **다른 선분끼리** end와 start를 비교하면 겹침을 알 수 있다고 생각했다

두 선분 `[s1, e1]`, `[s2, e2]`면

```
겹침 시작 = max(s1, s2)
겹침 끝   = min(e1, e2)
길이 = 겹침 끝 - 겹침 시작   # 양수일 때만
```

`s1 < e2` 이고 `s2 < e1`이면 겹친다

방향은 맞았다

다만 `lines`가 리스트라서 `lines[0][1]`, `lines[1][0]`처럼 꺼내야 하는데,  
그걸 `lines.end`처럼 써서 코드로 못 옮겼다

<br>

**3. 둘씩 구해서 더하면 중복이 생길 수 있다**

선분이 3개라서 1-2, 1-3, 2-3 겹침 길이를 그냥 더하면  
세 개가 한꺼번에 겹친 구간이 두 번 잡힐 수 있다

비교 아이디어는 맞지만, 합칠 때 중복을 빼야 한다

그래서 칸마다 몇 개 지나는지 세는 방식이 더 단순하다

---

## 정답

```python
def solution(lines):
    count = [0] * 201

    for start, end in lines:
        for i in range(start, end):
            count[i + 100] += 1

    answer = 0
    for c in count:
        if c >= 2:
            answer += 1

    return answer
```
