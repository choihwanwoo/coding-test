# 코딩테스트 연습 - 영어가 싫어요 (LV.0)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/120894)

## 풀이

**1. 영어 숫자를 0부터 9까지 순서대로 준비한다.**

```python
words = [
    'zero', 'one', 'two', 'three', 'four',
    'five', 'six', 'seven', 'eight', 'nine'
]
```

각 단어의 인덱스가 변환할 숫자와 같도록 만든다.

- `words[0]` → `'zero'`
- `words[1]` → `'one'`
- `words[9]` → `'nine'`

<br>

**2. `enumerate()`로 숫자와 영어 단어를 함께 가져온다.**

```python
for digit, word in enumerate(words):
```

`enumerate()`는 인덱스와 원소를 함께 꺼낸다.

```text
digit = 0, word = 'zero'
digit = 1, word = 'one'
...
digit = 9, word = 'nine'
```

<br>

**3. `replace()`로 영어 단어를 숫자 문자로 바꾼다.**

```python
numbers = numbers.replace(word, str(digit))
```

`replace(기존 문자열, 새 문자열)`는 해당 문자열을 찾아 바꾼 결과를 반환한다.

`digit`은 정수이므로 `str(digit)`으로 문자열로 바꿔 넣는다.

<span style="color:red">ex)</span> `numbers = 'onefourzerosixseven'`

```text
zero를 0으로 → onefour0sixseven
one을 1로   → 1four0sixseven
four를 4로  → 140sixseven
six를 6으로 → 1406seven
seven을 7로 → 14067
```

없는 단어를 바꾸려고 해도 문자열은 그대로라서 별도 조건문은 필요 없다.

각 영어 숫자 단어가 다른 영어 숫자 단어를 포함하지 않고, 새로 넣는 값도 숫자 문자이므로 이 방식으로 차례로 치환할 수 있다.

<br>

**4. 마지막에 `int()`로 정수로 변환한다.**

```python
return int(numbers)
```

변환이 끝난 `'14067'`은 아직 문자열이다.

문제는 정수를 반환하라고 했으므로 `int()`로 바꿔야 한다.

<span style="color:red">ex)</span>

- `'onetwothreefourfivesixseveneightnine'` → `123456789`
- `'onefourzerosixseven'` → `14067`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. `replace()`의 결과를 다시 저장해야 한다.**

```python
numbers.replace(word, str(digit))            # 결과를 저장하지 않음 ❌
numbers = numbers.replace(word, str(digit))  # ✅
```

Python 문자열은 직접 수정되지 않는다. `replace()`가 반환한 새 문자열을 변수에 다시 넣어야 한다.

<br>

**2. 바꿀 값도 문자열이어야 한다.**

```python
numbers.replace('one', 1)    # 정수라서 오류 ❌
numbers.replace('one', '1')  # 문자열로 바꾸기 ✅
```

반복문에서는 `str(digit)`을 사용한다.

<br>

**3. 중간에 0이 나올 수 있으므로 zero도 처리해야 한다.**

맨 앞에 `'zero'`가 올 수 없다는 조건은 중간에도 없다는 뜻이 아니다.

`'onezerozero'`는 `100`으로 변환되어야 한다.

<br>

**4. 같은 단어가 여러 번 나오면 모두 바꿔야 한다.**

```python
'oneoneone'.replace('one', '1')
# '111'
```

`replace()`는 횟수를 따로 제한하지 않으면 일치하는 부분을 모두 바꾼다.

세 번째 인자로 `1`을 넣으면 첫 번째 단어만 바뀌므로 이 문제에서는 필요 없다.

<br>

**5. 최종 결과를 문자열로 반환하면 안 된다.**

`'14067'`과 `14067`은 자료형이 다르다.

마지막에 `int(numbers)`를 반환해야 한다.

---

## 정답

```python
def solution(numbers):
    words = [
        'zero', 'one', 'two', 'three', 'four',
        'five', 'six', 'seven', 'eight', 'nine'
    ]

    for digit, word in enumerate(words):
        numbers = numbers.replace(word, str(digit))

    return int(numbers)
```

### 한 줄씩

- `words = [...]` → 0부터 9까지 영어 숫자를 순서대로 저장
- `enumerate(words)` → 숫자 인덱스와 영어 단어를 함께 가져오기
- `str(digit)` → 정수를 숫자 문자로 변환
- `numbers.replace(word, str(digit))` → 해당 영어 단어를 모두 숫자 문자로 치환
- `numbers = ...` → 변환 결과를 다시 저장
- `int(numbers)` → 완성된 숫자 문자열을 정수로 변환
- `return` → 정수 결과 반환

### 시간 복잡도

문자열 길이를 `N`이라고 하면, `replace()`로 문자열을 확인하는 작업을 10번 수행한다.

영어 숫자의 종류는 항상 10개이고 입력 길이는 최대 50이므로, 이 문제의 범위에서 **시간 복잡도는 O(N)**으로 정리할 수 있다.

치환한 문자열을 새로 만들기 때문에 **추가 공간 복잡도는 O(N)**이다.

### 한 줄 요약

> 0부터 9까지 영어 단어를 `replace()`로 숫자 문자로 바꾼 뒤, `int()`로 정수를 반환한다.
