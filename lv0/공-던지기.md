# 코딩테스트 연습 - 공 던지기 (LV.0)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/120843)

## 풀이

**1. 한 명을 건너뛰므로 인덱스는 2씩 이동한다.**

바로 옆 사람이 아니라 그다음 사람에게 던진다.

<span style="color:red">ex)</span> `numbers = [1, 2, 3, 4, 5, 6]`

```text
던지는 사람: 1 → 3 → 5 → 1 → 3 → ...
인덱스:      0 → 2 → 4 → 0 → 2 → ...
```

사람 번호와 달리 배열 인덱스는 `0`부터 시작한다.

<br>

**2. k번째 던지는 사람까지는 k - 1번 이동한다.**

첫 번째로 던지는 사람은 처음 공을 가진 1번이다.

- 첫 번째 → 이동 0번 → 인덱스 `0`
- 두 번째 → 이동 1번 → 인덱스 `2`
- 세 번째 → 이동 2번 → 인덱스 `4`

따라서 원을 도는 것을 고려하기 전의 이동량은 다음과 같다.

```python
2 * (k - 1)
```

<br>

**3. 나머지 연산으로 배열 끝에서 처음으로 돌아온다.**

```python
index = (2 * (k - 1)) % len(numbers)
```

동그랗게 서 있으므로 마지막 사람 다음에는 첫 번째 사람이 온다.

배열 길이로 나눈 나머지를 사용하면 인덱스를 항상 `0`부터 `len(numbers) - 1` 사이로 맞출 수 있다.

<span style="color:red">ex)</span> 친구 6명, `k = 5`

```python
2 * (5 - 1)  # 8칸 이동
8 % 6       # 인덱스 2
numbers[2]  # 3번
```

<br>

**4. 계산한 인덱스의 사람 번호를 반환한다.**

```python
return numbers[(2 * (k - 1)) % len(numbers)]
```

반환해야 하는 것은 인덱스가 아니라 그 자리에 있는 사람의 번호다.

<span style="color:red">ex)</span>

- `[1, 2, 3, 4]`, `k = 2` → 인덱스 `2 % 4 = 2` → 결과 `3`
- `[1, 2, 3, 4, 5, 6]`, `k = 5` → 인덱스 `8 % 6 = 2` → 결과 `3`
- `[1, 2, 3]`, `k = 3` → 인덱스 `4 % 3 = 1` → 결과 `2`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. k번째 받는 사람과 던지는 사람을 혼동하면 안 된다.**

`k = 1`이면 1번이 3번에게 던진다.

이 문제의 정답은 받은 사람인 3번이 아니라 **던진 사람인 1번**이다.

```python
2 * k        # k번째 받는 사람까지의 이동량 ❌
2 * (k - 1)  # k번째 던지는 사람까지의 이동량 ✅
```

<br>

**2. 한 명을 건너뛴다는 것은 한 칸 이동이 아니다.**

1번에서 2번을 건너뛰고 3번에게 던지므로 **두 칸씩** 이동한다.

따라서 이동 횟수에 `2`를 곱해야 한다.

<br>

**3. 배열 길이를 넘어가는 경우도 처리해야 한다.**

```python
numbers[2 * (k - 1)]  # 인덱스가 범위를 벗어날 수 있음 ❌
```

`% len(numbers)`를 적용해야 원을 여러 바퀴 돌아도 올바른 위치를 구할 수 있다.

<br>

**4. 사람이 홀수 명이어도 같은 공식을 사용한다.**

3명일 때 던지는 사람의 순서는 다음과 같다.

```text
1 → 3 → 2 → 1 → ...
```

처음에 홀수 번호에게 던진다고 해서 홀수 번호만 계속 공을 받는 것은 아니다.

전체 배열 길이로 나머지를 구하면 홀수 명과 짝수 명을 따로 나누지 않아도 된다.

<br>

**5. 인덱스 자체를 반환하면 안 된다.**

첫 번째 예제에서 계산한 인덱스는 `2`지만, 그 자리에 있는 사람 번호는 `3`이다.

반드시 `numbers[index]`를 반환한다.

---

## 정답

```python
def solution(numbers, k):
    return numbers[(2 * (k - 1)) % len(numbers)]
```

### 한 줄씩

- `k - 1` → k번째로 던지기 전까지 공이 전달된 횟수
- `2 * (k - 1)` → 한 명씩 건너뛰며 이동한 총 칸 수
- `% len(numbers)` → 원을 돌아 배열 안의 인덱스로 변환
- `numbers[...]` → 해당 인덱스에 있는 사람 번호
- `return` → k번째로 공을 던지는 사람의 번호 반환

### 시간 복잡도

반복문 없이 산술 연산과 배열 접근으로 구하므로 **시간 복잡도와 추가 공간 복잡도는 모두 O(1)**이다.

### 한 줄 요약

> k번째 던지는 사람은 처음 위치에서 `2 * (k - 1)`칸 이동한 사람이므로, 배열 길이로 나눈 나머지를 인덱스로 사용한다.
