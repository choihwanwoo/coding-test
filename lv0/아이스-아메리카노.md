# 코딩테스트 연습 - 아이스 아메리카노 (LV.0)

## 풀이

**1. 몇 잔 살 수 있는지는 몫, 남는 돈은 나머지다**

아메리카노 한 잔이 `5500`원이니까

- 마실 수 있는 잔 수 → `money`를 `5500`으로 나눈 **몫**
- 남는 돈 → `money`를 `5500`으로 나눈 **나머지**

라고 생각하였다

<span style="color:red">ex)</span> `money = 15000`

- `15000 // 5500 = 2` → 2잔
- `15000 % 5500 = 4000` → 4000원 남음
- 결과: `[2, 4000]`

<br>

**2. 파이썬은 `//`가 몫, `%`가 나머지다**

```python
money // 5500   # 몫
money % 5500    # 나머지
```

`/`를 쓰면 `2.727...`처럼 소수가 나오니까  
잔 수는 반드시 `//`로 구해야 한다

<br>

**3. 둘을 리스트에 담아서 반환한다**

문제에서 **잔 수, 남는 돈** 순서대로 담으라고 했으니까

```python
return [money // 5500, money % 5500]
```

<span style="color:red">ex)</span> `money = 5500`

- `5500 // 5500 = 1`
- `5500 % 5500 = 0`
- 결과: `[1, 0]`

---

## 오답노트

**1. `/`로 나누면 잔 수가 소수로 나온다**

```python
money / 5500   # 15000 / 5500 = 2.727... ❌
```

잔은 정수로만 살 수 있으니까 `//`를 써야 한다

<br>

**2. 남는 돈을 `money - 5500`으로 구하면 안 된다**

한 잔 값만 빼면 **한 잔 샀을 때**의 잔돈이다

여러 잔을 사고 남은 돈은 `money % 5500`이다

<span style="color:red">ex)</span> `money = 15000`

- `15000 - 5500 = 9500` ❌
- `15000 % 5500 = 4000` ✅

<br>

**3. 반환 순서는 [잔 수, 남는 돈]이다**

`[4000, 2]`처럼 순서를 바꾸면 틀린다

---

## 정답

```python
def solution(money):
    return [money // 5500, money % 5500]
```

### 한 줄씩

| 코드 | 의미 |
|------|------|
| `money // 5500` | 살 수 있는 잔 수 (몫) |
| `money % 5500` | 남는 돈 (나머지) |
| `[잔 수, 남는 돈]` | 문제에서 요구한 순서대로 반환 |
