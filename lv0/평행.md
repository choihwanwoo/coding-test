# 코딩테스트 연습 - 평행 (LV.0)

## 풀이

**1. 점 4개로 선분 2개를 만들었을 때, 기울기가 같은 경우가 있으면 1**

`dots`에 점 4개가 들어 있다

두 점씩 이어서 선분 2개를 만드는 방법이 여러 가지고,  
그중 **기울기가 같은 짝**이 하나라도 있으면 `1`, 없으면 `0`

<span style="color:red">ex)</span>

- `[[1, 4], [9, 2], [3, 8], [11, 6]]` → `1`
- `[[3, 5], [4, 1], [2, 4], [5, 10]]` → `0`

<br>

**2. 기울기가 같다 = 평행하다**

두 점 `(x1, y1)`, `(x2, y2)`의 기울기

```
(y2 - y1) / (x2 - x1)
```

문제에서 x축·y축에 평행한 경우는 없다고 해서,  
나누기 0은 신경 안 써도 된다

다만 소수 나눗셈은 오차가 날 수 있어서,  
같음을 이렇게 비교한다

```
(y2 - y1) / (x2 - x1) == (y4 - y3) / (x4 - x3)
```

양변에 분모를 곱하면

```
(y2 - y1) * (x4 - x3) == (y4 - y3) * (x2 - x1)
```

나눗셈 없이 정수끼리만 비교할 수 있다

<br>

**3. 점 4개를 두 선분으로 묶는 방법은 3가지다**

점을 `A B C D`라고 하면

| 선분1 | 선분2 |
|-------|-------|
| A-B | C-D |
| A-C | B-D |
| A-D | B-C |

이 세 경우만 보면 된다

하나라도 기울기가 같으면 `1`을 반환한다

<span style="color:red">ex)</span> `[[1, 4], [9, 2], [3, 8], [11, 6]]`

- `[1,4]`-`[3,8]` 기울기: `(8-4)/(3-1) = 2`
- `[9,2]`-`[11,6]` 기울기: `(6-2)/(11-9) = 2`
- 같음 → `1`

---

## 오답노트

**1. 점 4개를 어떻게 짝지어야 할지 헷갈릴 수 있다**

아무 두 점이나 이으면 되는 게 아니라,  
**겹치지 않게 두 선분으로 나누는** 경우만 보면 된다

그래서 위 3가지 조합만 검사하면 충분하다

<br>

**2. 기울기를 `/`로 바로 비교하면 위험하다**

파이썬에서 `/`는 실수 나눗셈이라 값이 미세하게 다를 수 있다

곱셈으로 바꿔서 비교하는 편이 안전하다

---

## 정답

```python
def solution(dots):
    def parallel(a, b, c, d):
        # 선분 a-b 와 c-d 가 평행한지
        x1, y1 = dots[a]
        x2, y2 = dots[b]
        x3, y3 = dots[c]
        x4, y4 = dots[d]
        return (y2 - y1) * (x4 - x3) == (y4 - y3) * (x2 - x1)

    if parallel(0, 1, 2, 3):
        return 1
    if parallel(0, 2, 1, 3):
        return 1
    if parallel(0, 3, 1, 2):
        return 1
    return 0
```
