# 코딩테스트 연습 - 배열 두배 만들기 (LV.0)

## 풀이

**1. 결과 배열을 원본이랑 같은 길이로 만든다.**

초기 코드는 `int[] answer = {}`라서 칸이 0개다.

값을 넣을 자리가 없으니 `new int[numbers.length]`로 **numbers와 같은 길이**의 배열을 만들어야 한다고 생각하였다.

`return answer` 형태는 그대로 둔다.

<br>

**2. for문으로 원소를 하나씩 2배 한다.**

배열은 통째로 `+` 하거나 `* 2` 하는 게 아니다.

`numbers[i]`로 i번째 값을 꺼내고, `answer[i] = numbers[i] * 2`로 넣는다.

이걸 `i = 0`부터 `numbers.length` 전까지 반복하면 된다고 생각하였다.

<span style="color:red">ex)</span> `numbers = [1, 2, 3, 4, 5]`

- i=0: `1 * 2 = 2`
- i=1: `2 * 2 = 4`
- i=2: `3 * 2 = 6`
- i=3: `4 * 2 = 8`
- i=4: `5 * 2 = 10`
- 결과: `[2, 4, 6, 8, 10]`

---

## 오답노트

**1. 배열을 어떻게 쓰는지 몰랐다.**

처음에 배열이 뭔지, `[i]`로 칸에 접근하는 법을 잘 몰랐다.

정리하면 이렇다.

| 코드 | 의미 |
|------|------|
| `numbers` | 배열 전체 (여러 칸이 묶인 것) |
| `numbers.length` | 칸 개수 (길이) |
| `numbers[i]` | i번째 칸의 값 |
| `new int[n]` | 정수 칸 n개를 새로 만듦 (처음 값은 전부 0) |

<br>

**2. `numbers = new int[5]`를 했다.**

입력으로 받은 `numbers`를 버리고, 길이 5짜리 **새 빈 배열**로 덮어썼다.

`new int[5]`는 칸만 만들고 값은 안 넣으니까 전부 `0`이다.

그래서 결과가 `[0, 0, 0, 0, 0]`만 나왔다.

<span style="color:red">ex)</span>

```java
// 원래 numbers = [1, 2, 3, 4, 5] 였는데
numbers = new int[5];  // → [0, 0, 0, 0, 0] 으로 바뀜
```

`numbers`는 이미 매개변수로 들어와 있다.  
다시 `new`로 만들 필요 없고, **있는 값을 읽어서** `answer`에 넣으면 된다.

<br>

**3. `answer = {answer + numbers}`처럼 배열끼리 더하려고 했다.**

자바에서 배열은 `+`로 합치거나 한꺼번에 연산할 수 없다.

원소 단위로 for문을 돌려야 한다.

<br>

**4. `int[] answer = {}`를 그대로 두면 안 된다.**

`{}`는 길이 0짜리 배열이다.

템플릿을 최대한 유지하고 싶어도, 이 줄은 `new int[numbers.length]`로 바꿔야 한다.

`return answer`만 남기고 가운데를 채우는 식이면 충분하다.

---

## 정답

```java
class Solution {
    public int[] solution(int[] numbers) {
        int[] answer = new int[numbers.length];

        for (int i = 0; i < numbers.length; i++) {
            answer[i] = numbers[i] * 2;
        }

        return answer;
    }
}
```
