# 코딩테스트 연습 - 다항식 더하기 (LV.0)

## 풀이

`"3x + 7 + x"` 같은 문자열을 받아서, 같은 종류끼리 더해 `"4x + 7"`로 만든다

**1단계** `" + "`로 자른다  
→ `["3x", "7", "x"]`

**2단계** x 있는 항 / 숫자만 있는 항을 따로 더한다  
→ x는 `4`, 상수는 `7`

**3단계** 다시 붙인다  
→ `"4x + 7"` (`x`만 있으면 계수 1, `1x`는 쓰면 안 됨)

---

## 오답노트

- `"x"`는 숫자 1이다
- 상수는 맨 뒤에 `" + 7"`처럼 붙인다

---

## 정답

```python
def solution(polynomial):
    x_sum = 0
    num_sum = 0

    for term in polynomial.split(" + "):
        if 'x' in term:
            x_sum += 1 if term == 'x' else int(term.replace('x', ''))
        else:
            num_sum += int(term)

    if x_sum == 1:
        answer = 'x'
    elif x_sum > 1:
        answer = str(x_sum) + 'x'
    else:
        answer = ''

    if num_sum > 0:
        answer = answer + ' + ' + str(num_sum) if answer else str(num_sum)

    return answer
```
