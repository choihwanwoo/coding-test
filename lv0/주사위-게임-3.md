# 코딩테스트 연습 - 주사위 게임 3 (LV.0)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/181916)

## 풀이

**1. 각 숫자가 몇 번 나왔는지 센다.**

숫자 자체보다 **같은 숫자가 몇 개 있는지**가 중요하다.

Python의 `Counter`를 사용하면 숫자별 등장 횟수를 구할 수 있다.

```python
from collections import Counter

counts = Counter([a, b, c, d])
```

<span style="color:red">ex)</span> `4, 1, 4, 4`

```python
# 숫자 4는 3번, 숫자 1은 1번
# {4: 3, 1: 1}
```

`len(counts)`는 주사위 개수가 아니라 **서로 다른 숫자의 종류 수**다.

<br>

**2. 숫자 종류가 1개면 네 개가 모두 같다.**

```python
if len(counts) == 1:
    return 1111 * a
```

모두 같은 숫자이므로 `a`를 사용해도 된다.

<span style="color:red">ex)</span> `2, 2, 2, 2` → `1111 * 2 = 2222`

<br>

**3. 숫자 종류가 2개면 3+1인지 2+2인지 구분한다.**

```python
(p, p_count), (q, q_count) = counts.most_common()
```

`most_common()`은 **많이 나온 숫자부터** `(숫자, 횟수)` 형태로 반환한다.

- `p_count == 3` → 세 개가 같고 하나만 다름
- 그 외 → 두 개씩 같음

세 개가 같으면 다음 식을 사용한다.

```python
(10 * p + q) ** 2
```

<span style="color:red">ex)</span> `4, 1, 4, 4`

`p = 4`, `q = 1`이므로 `(10 * 4 + 1) ** 2 = 1681`이다.

두 개씩 같으면 다음 식을 사용한다.

```python
(p + q) * abs(p - q)
```

<span style="color:red">ex)</span> `6, 3, 3, 6`

`(6 + 3) * abs(6 - 3) = 27`이다.

두 숫자의 등장 횟수가 같아도 이 식은 p와 q의 순서에 영향을 받지 않는다.

<br>

**4. 숫자 종류가 3개면 한 번씩 나온 두 숫자를 곱한다.**

네 개의 주사위에서 숫자가 세 종류라면 등장 횟수는 반드시 **2+1+1**이다.

두 번 나온 숫자를 제외하고, 한 번씩 나온 숫자 두 개만 찾는다.

```python
q, r = [number for number, count in counts.items() if count == 1]
return q * r
```

`counts.items()`는 `(숫자, 횟수)`를 하나씩 가져온다.

<span style="color:red">ex)</span> `2, 5, 2, 6`

- 2는 두 번 나왔으므로 제외
- 5와 6은 한 번씩 나왔으므로 `5 * 6 = 30`

<br>

**5. 숫자 종류가 4개면 가장 작은 숫자를 반환한다.**

```python
return min(a, b, c, d)
```

앞의 경우들을 모두 처리했다면 남은 경우는 네 숫자가 전부 다른 경우다.

<span style="color:red">ex)</span> `6, 4, 2, 5` → 가장 작은 숫자인 `2`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 숫자 종류가 2개라고 무조건 2+2는 아니다.**

- `4, 4, 4, 1` → 3+1
- `4, 4, 1, 1` → 2+2

종류 수만 확인하지 말고 등장 횟수까지 확인해야 한다.

<br>

**2. 3+1에서는 세 번 나온 숫자가 p다.**

`(10 * p + q) ** 2`는 p와 q를 바꾸면 결과가 달라진다.

```python
(10 * 4 + 1) ** 2  # 1681 ✅
(10 * 1 + 4) ** 2  # 196 ❌
```

`most_common()`으로 등장 횟수가 많은 숫자를 먼저 가져오면 p를 찾기 쉽다.

<br>

**3. 제곱은 `^`가 아니라 `**`다.**

```python
(10 * p + q) ** 2  # 제곱 ✅
```

Python의 `^`는 제곱이 아니라 비트 XOR 연산이다.

<br>

**4. 두 쌍인 경우에는 차이의 절댓값이 필요하다.**

```python
(p + q) * abs(p - q)
```

p가 q보다 작으면 `p - q`가 음수다. 문제의 `|p - q|`는 `abs(p - q)`로 표현한다.

<br>

**5. 2+1+1에서는 중복된 숫자를 곱하지 않는다.**

`2, 5, 2, 6`이라면 곱할 숫자는 `2`가 아니라 **5와 6**이다.

`count == 1`인 숫자만 골라야 한다.

## 정답

```python
from collections import Counter


def solution(a, b, c, d):
    counts = Counter([a, b, c, d])

    if len(counts) == 1:
        return 1111 * a

    if len(counts) == 2:
        (p, p_count), (q, q_count) = counts.most_common()

        if p_count == 3:
            return (10 * p + q) ** 2

        return (p + q) * abs(p - q)

    if len(counts) == 3:
        q, r = [number for number, count in counts.items() if count == 1]
        return q * r

    return min(a, b, c, d)
```

### 한 줄씩

- `Counter([a, b, c, d])` → 숫자별 등장 횟수 계산
- `len(counts)` → 서로 다른 숫자의 종류 수
- `1111 * a` → 네 숫자가 모두 같은 경우
- `counts.most_common()` → 등장 횟수가 많은 숫자부터 가져오기
- `p_count == 3` → 세 개가 같고 하나만 다른 경우
- `(10 * p + q) ** 2` → 세 번 나온 숫자를 p로 두고 점수 계산
- `(p + q) * abs(p - q)` → 두 개씩 같은 경우의 점수
- `count == 1` → 한 번만 나온 숫자 선택
- `q * r` → 2+1+1에서 서로 다른 두 숫자의 곱
- `min(a, b, c, d)` → 모두 다르면 최솟값 반환

### 시간 복잡도

주사위는 항상 네 개이므로 등장 횟수를 세고 분기하는 데 필요한 작업량이 일정하다.

따라서 **시간 복잡도와 공간 복잡도는 모두 O(1)**이다.
