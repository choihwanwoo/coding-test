# 코딩테스트 연습 - 택배 상자 꺼내기 (LV.1)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/389478)

## 풀이

**1. 꺼낼 상자와 같은 열에 있는 위쪽 상자만 세면 된다.**

상자를 꺼내려면 그 상자 바로 위에 쌓인 상자들을 먼저 꺼내야 한다.

다른 열의 상자는 꺼낼 필요가 없다.

따라서 **꺼낼 상자와 같은 열에 있으면서, 그 상자보다 위에 있는 상자**를 찾으면 된다.

문제는 꺼내려는 상자 자체도 개수에 포함한다.

<span style="color:red">ex)</span> `n = 22`, `w = 6`, `num = 8`

- 8번 위에는 17번과 20번이 있음
- 꺼내는 순서 → `20 → 17 → 8`
- 결과 → `3`

<br>

**2. 상자 번호에서 1을 빼고 층과 위치를 구한다.**

```python
row = (box - 1) // w
col = (box - 1) % w
```

- `row` → 아래에서부터 몇 번째 층인지, `0`부터 계산
- `col` → 그 층에서 몇 번째로 놓은 상자인지, `0`부터 계산

상자는 1번부터 시작하므로 `box - 1`로 바꾼다.

<span style="color:red">ex)</span> `box = 8`, `w = 6`

```python
row = (8 - 1) // 6  # 1
col = (8 - 1) % 6   # 1
```

8번은 아래에서 두 번째 층의 두 번째로 놓은 상자다.

다만 이 층은 오른쪽부터 놓으므로, 아직 `col`이 왼쪽 기준의 실제 열은 아니다.

<br>

**3. 홀수 층에서는 열 위치를 뒤집는다.**

층을 `0`부터 세면 쌓는 방향은 다음과 같다.

- `0, 2, 4, ...`층 → 왼쪽에서 오른쪽
- `1, 3, 5, ...`층 → 오른쪽에서 왼쪽

홀수 층의 열을 왼쪽 기준으로 바꾸려면 다음 식을 사용한다.

```python
if row % 2 == 1:
    col = w - 1 - col
```

<span style="color:red">ex)</span> 가로가 6칸인 홀수 층

```text
왼쪽 기준 열:  0   1   2   3   4   5
상자 번호:   12  11  10   9   8   7
```

8번의 실제 열은 `6 - 1 - 1 = 4`다.

같은 방법으로 계산하면 17번과 20번도 열이 `4`이므로, 8번 위에 있는 상자라는 것을 알 수 있다.

<br>

**4. `num`부터 `n`까지 같은 열의 상자를 센다.**

```python
for box in range(num, n + 1):
```

번호가 클수록 나중에 쌓은 상자다.

`num`보다 큰 번호 중 같은 열에 있는 상자는 모두 위층에 있다. 같은 층에는 같은 열의 상자가 하나뿐이기 때문이다.

`num`부터 확인하면 꺼내려는 상자 자신도 자연스럽게 포함된다.

```python
if get_col(box) == target_col:
    answer += 1
```

실제로 존재하는 `1~n`번 상자만 계산하므로, 맨 위층이 덜 채워진 경우에도 빈칸을 잘못 세지 않는다.

<br>

**5. 두 번째 예제에도 적용해 본다.**

<span style="color:red">ex)</span> `n = 13`, `w = 3`, `num = 6`

```text
13
12 11 10
 7  8  9
 6  5  4
 1  2  3
```

- 6번 상자의 열은 `0`
- 6번 이상 중 열이 `0`인 상자 → `6, 7, 12, 13`
- 실제 꺼내는 순서 → `13 → 12 → 7 → 6`
- 결과 → `4`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 홀수 층에서는 나머지를 그대로 열로 쓰면 안 된다.**

```python
col = (box - 1) % w
```

이 값은 그 층에서 놓은 순서다. 오른쪽부터 쌓는 층에서는 실제 열과 다르다.

홀수 층이라면 반드시 `w - 1 - col`로 뒤집어야 한다.

<br>

**2. `box // w`로 층을 구하면 경계에서 틀린다.**

<span style="color:red">ex)</span> `box = 6`, `w = 6`

```python
6 // 6        # 1 → 두 번째 층으로 잘못 계산 ❌
(6 - 1) // 6  # 0 → 첫 번째 층 ✅
```

번호가 1부터 시작하므로 몫과 나머지를 구하기 전에 1을 빼야 한다.

<br>

**3. 전체 층수만 보고 개수를 구하면 맨 위층에서 틀릴 수 있다.**

맨 위층에는 상자가 `w`개보다 적게 있을 수 있다.

```python
n = 7
w = 3
num = 3
```

3번 위에는 4번만 있고, 맨 위층의 7번은 다른 열에 있다.

따라서 결과는 `3, 4` 두 개다. 실제 존재하는 상자의 열을 확인하면 이 경우도 처리된다.

<br>

**4. 꺼내려는 상자 자신도 포함해야 한다.**

`range(num + 1, n + 1)`로 위쪽만 세면 정답보다 1 작아진다.

`range(num, n + 1)`로 시작해서 자기 자신도 함께 센다.

---

## 정답

```python
def solution(n, w, num):
    def get_col(box):
        row = (box - 1) // w
        col = (box - 1) % w

        if row % 2 == 1:
            col = w - 1 - col

        return col

    target_col = get_col(num)
    answer = 0

    for box in range(num, n + 1):
        if get_col(box) == target_col:
            answer += 1

    return answer
```

### 한 줄씩

- `def get_col(box):` → 상자의 실제 열을 구하는 함수
- `(box - 1) // w` → 아래에서부터 층 번호 계산
- `(box - 1) % w` → 그 층에서 놓은 순서 계산
- `row % 2 == 1` → 오른쪽부터 쌓는 층인지 확인
- `w - 1 - col` → 왼쪽 기준의 실제 열로 변환
- `target_col = get_col(num)` → 꺼낼 상자의 열 저장
- `range(num, n + 1)` → 자기 자신과 이후에 쌓은 상자 확인
- `get_col(box) == target_col` → 같은 열의 상자인지 비교
- `answer += 1` → 꺼내야 하는 상자 개수 증가
- `return answer` → 꺼낼 상자를 포함한 총개수 반환

### 시간 복잡도

`num`번부터 `n`번까지 각 상자의 열을 한 번씩 계산하므로 시간 복잡도는 **O(n - num + 1)**, 최악의 경우 **O(n)**이다.

상자를 담는 배열을 만들지 않으므로 추가 공간 복잡도는 **O(1)**이다.

### 한 줄 요약

> 홀수 층의 열을 뒤집어 실제 위치를 구하고, 꺼낼 상자부터 마지막 상자까지 같은 열에 있는 상자를 센다.
