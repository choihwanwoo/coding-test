# 코딩테스트 연습 - 추억 점수 (LV.1)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/176963)

## 풀이

**1. 이름과 그리움 점수를 연결한다.**

`name`과 `yearning`의 같은 인덱스는 같은 사람의 정보다.

```python
name = ['may', 'kein', 'kain', 'radi']
yearning = [5, 10, 1, 3]
```

이름으로 점수를 바로 찾을 수 있도록 딕셔너리를 만든다.

```python
score = dict(zip(name, yearning))
```

`zip()`은 두 배열에서 같은 위치의 값을 하나씩 묶는다. 이를 `dict()`에 넣으면 이름이 키, 점수가 값이 된다.

```python
{'may': 5, 'kein': 10, 'kain': 1, 'radi': 3}
```

<br>

**2. 사진 하나마다 합계를 0으로 시작한다.**

`photo`는 사진 여러 장을 담은 이차원 배열이다.

```python
for people in photo:
    total = 0
```

`people`에는 사진 한 장에 나온 사람들의 이름이 들어 있다.

사진별 점수를 구해야 하므로 사진이 바뀔 때마다 `total`을 초기화한다.

<br>

**3. 등록된 사람의 점수를 더하고, 없는 사람은 0점으로 처리한다.**

```python
for person in people:
    total += score.get(person, 0)
```

`딕셔너리.get(키, 기본값)`은 키가 있으면 해당 값을, 없으면 기본값을 반환한다.

<span style="color:red">ex)</span>

```python
score.get('may', 0)   # 5
score.get('brin', 0)  # 0
```

별도 조건문 없이 그리움 점수가 없는 사람을 0점으로 처리할 수 있다.

<br>

**4. 사진별 합계를 순서대로 저장한다.**

```python
answer.append(total)
```

사진 한 장의 계산이 끝나면 결과 리스트에 점수 하나를 추가한다.

입력 사진 순서대로 처리하므로 결과도 같은 순서를 유지한다.

<span style="color:red">ex)</span> 첫 번째 예제

- `['may', 'kein', 'kain', 'radi']` → `5 + 10 + 1 + 3 = 19`
- `['may', 'kein', 'brin', 'deny']` → `5 + 10 + 0 + 0 = 15`
- `['kon', 'kain', 'may', 'coni']` → `0 + 1 + 5 + 0 = 6`

결과는 `[19, 15, 6]`이다.

<span style="color:red">ex)</span> 두 번째 예제

`kali`, `mari`, `don`의 점수가 각각 `11`, `1`, `55`라면

- `['kali', 'mari', 'don']` → `67`
- `['pony', 'tom', 'teddy']` → 등록된 사람이 없으므로 `0`
- `['con', 'mona', 'don']` → don의 점수만 더해서 `55`

결과는 `[67, 0, 55]`다.

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 딕셔너리에 없는 이름을 대괄호로 조회하면 오류가 난다.**

```python
score['brin']        # 등록되지 않은 이름이면 KeyError ❌
score.get('brin', 0) # 없으면 0 ✅
```

사진에는 `name`에 없는 사람도 나올 수 있다.

또한 `score.get(person)`만 쓰면 없는 이름에 대해 `None`이 나오므로, 합계에 더할 기본값 `0`을 지정해야 한다.

<br>

**2. 사진마다 합계를 초기화해야 한다.**

```python
for people in photo:
    total = 0
```

`total = 0`을 사진 반복문 밖에만 두면 이전 사진 점수까지 누적된다.

이 문제는 모든 사진의 총점이 아니라 **각 사진의 점수**를 구하는 문제다.

<br>

**3. 아무도 등록되어 있지 않은 사진도 결과에 넣어야 한다.**

사진 속 모든 사람이 `name`에 없으면 점수는 `0`이다.

그 사진을 건너뛰지 말고 `answer`에 `0`을 추가해야 한다.

결과 리스트의 길이는 항상 사진 수와 같아야 한다.

<br>

**4. 결과를 정렬하면 안 된다.**

점수가 큰 순서가 아니라 **photo에 주어진 순서**로 반환해야 한다.

입력 순서대로 `append()`하면 된다.

## 정답

```python
def solution(name, yearning, photo):
    score = dict(zip(name, yearning))
    answer = []

    for people in photo:
        total = 0

        for person in people:
            total += score.get(person, 0)

        answer.append(total)

    return answer
```

### 한 줄씩

- `zip(name, yearning)` → 같은 위치의 이름과 점수를 짝짓기
- `dict(...)` → 이름으로 점수를 찾는 딕셔너리 만들기
- `answer = []` → 사진별 점수를 담을 리스트
- `for people in photo:` → 사진을 한 장씩 확인
- `total = 0` → 현재 사진의 합계 초기화
- `for person in people:` → 사진 속 인물을 한 명씩 확인
- `score.get(person, 0)` → 등록된 점수 또는 기본값 0 가져오기
- `total += ...` → 현재 사진의 추억 점수에 더하기
- `answer.append(total)` → 계산한 사진 점수를 순서대로 저장
- `return answer` → 사진별 추억 점수 리스트 반환

### 시간 복잡도

등록된 사람 수를 `N`, 사진 수를 `P`, 모든 사진에 나온 인물 수의 합을 `T`라고 하자.

딕셔너리를 만드는 데 O(N), 사진 속 인물들을 확인하는 데 평균 O(T)가 걸린다. 이름 길이가 최대 7이고 딕셔너리 조회가 평균 O(1)이라는 기준에서 **시간 복잡도는 O(N + T)**다.

딕셔너리와 결과 리스트를 저장하므로 **결과를 포함한 추가 공간 복잡도는 O(N + P)**다.

### 한 줄 요약

> 이름과 점수를 딕셔너리로 연결하고, 사진마다 `get(이름, 0)`으로 가져온 점수를 합산한다.
