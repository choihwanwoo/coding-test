# 코딩테스트 연습 - 가장 많이 받은 선물 (LV.1)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/258712)

## 풀이

**1. 두 사람 사이의 기록을 먼저 비교한다.**

다음 달에 선물을 받을 사람을 정하는 순서는 다음과 같다.

- 두 사람 중 상대에게 더 많이 준 사람이 선물을 하나 받는다.
- 주고받은 개수가 같거나 둘 다 준 적이 없다면 선물 지수를 비교한다.
- 선물 지수도 같으면 서로 주고받지 않는다.

선물 지수는 **친구 전체에게 준 선물 수 - 친구 전체에게 받은 선물 수**다.

<span style="color:red">ex)</span> A가 B에게 5개, B가 A에게 3개를 줬다면

A가 더 많이 줬으므로 다음 달에 A가 B에게 선물을 **하나** 받는다.

차이가 2개여도 다음 달에 받는 것은 1개다.

<br>

**2. 친구 이름을 숫자 인덱스로 바꾼다.**

```python
index = {name: i for i, name in enumerate(friends)}
```

<span style="color:red">ex)</span>

```python
friends = ["muzi", "ryan", "frodo", "neo"]
# {"muzi": 0, "ryan": 1, "frodo": 2, "neo": 3}
```

딕셔너리로 이름에 해당하는 번호를 바로 찾을 수 있다.

<br>

**3. 선물 기록과 선물 지수를 함께 저장한다.**

```python
record = [[0] * n for _ in range(n)]
score = [0] * n
```

- `record[a][b]` → a가 b에게 준 선물 수
- `score[a]` → a의 선물 지수

기록 하나를 읽을 때마다 다음과 같이 갱신한다.

```python
record[a][b] += 1
score[a] += 1
score[b] -= 1
```

준 사람의 지수는 1 증가하고, 받은 사람의 지수는 1 감소한다.

같은 기록이 여러 번 나올 수 있으므로 `= 1`이 아니라 `+= 1`로 누적해야 한다.

<br>

**4. 모든 친구 쌍을 한 번씩만 비교한다.**

```python
for i in range(n):
    for j in range(i + 1, n):
```

`j`를 `i + 1`부터 시작하면 자기 자신은 제외되고, 같은 두 사람을 중복해서 비교하지 않는다.

먼저 `record[i][j]`와 `record[j][i]`를 비교한다.

두 값이 같을 때만 `score[i]`와 `score[j]`를 비교한다.

다음 달에 받는 개수는 별도의 `received` 배열에 저장한다.

<br>

**5. 다음 달 받는 개수 중 최댓값을 반환한다.**

```python
return max(received)
```

반환할 값은 친구 이름이나 선물 지수가 아니라 **다음 달에 가장 많이 받는 사람이 받을 선물 개수**다.

<span style="color:red">ex)</span> 첫 번째 예제

- 선물 지수 → `muzi: -3`, `ryan: 2`, `frodo: 0`, `neo: 1`
- muzi와 ryan → ryan이 더 많이 줬으므로 ryan이 받음
- muzi와 frodo → muzi가 더 많이 줬으므로 muzi가 받음
- muzi와 neo → neo가 더 많이 줬으므로 neo가 받음
- ryan과 frodo → frodo가 더 많이 줬으므로 frodo가 받음
- ryan과 neo → 기록이 없고 ryan의 선물 지수가 높으므로 ryan이 받음
- frodo와 neo → 기록이 없고 neo의 선물 지수가 높으므로 neo가 받음

```python
received = [1, 2, 1, 2]
```

가장 많이 받는 개수는 `2`다.

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 선물 지수를 먼저 비교하면 안 된다.**

두 사람 사이에서 주고받은 개수가 다르면 그 기록으로 결정한다.

전체 선물 지수가 더 낮더라도, 상대에게 더 많이 줬다면 다음 달에 선물을 받는다.

선물 지수는 **두 사람 사이의 기록이 같을 때만** 사용한다.

<br>

**2. 선물 지수는 준 개수에서 받은 개수를 뺀다.**

```python
score[a] += 1  # 준 사람
score[b] -= 1  # 받은 사람
```

반대로 계산하면 기록이 같은 경우에 선물을 받을 사람이 뒤바뀐다.

<br>

**3. 이번 달 기록과 다음 달 결과를 섞으면 안 된다.**

친구 쌍을 비교하는 도중 `record`나 `score`를 바꾸면, 앞에서 예측한 결과가 뒤의 판단에 영향을 준다.

모든 비교는 **이번 달까지의 동일한 기록**을 기준으로 한다.

다음 달 결과만 `received`에 따로 누적한다.

<br>

**4. 기록도 같고 선물 지수도 같으면 아무것도 더하지 않는다.**

세 번째 예제는 모든 친구의 선물 지수가 `0`이고, 두 사람 사이의 기록도 각각 같다.

따라서 누구도 받지 않으며 결과는 `0`이다.

`>=`로 비교하면 같은 경우에도 한쪽에게 선물을 잘못 추가하므로 `>`와 `<`를 사용한다.

<br>

**5. 이차원 배열은 각 행을 따로 만들어야 한다.**

```python
record = [[0] * n] * n               # 같은 행을 공유하므로 주의 ❌
record = [[0] * n for _ in range(n)]  # 행마다 별도 리스트 ✅
```

첫 번째 방식은 한 행의 값을 바꾸면 다른 행에도 같은 변경이 나타난다.

## 정답

```python
def solution(friends, gifts):
    n = len(friends)
    index = {name: i for i, name in enumerate(friends)}
    record = [[0] * n for _ in range(n)]
    score = [0] * n

    for gift in gifts:
        giver, receiver = gift.split()
        a = index[giver]
        b = index[receiver]

        record[a][b] += 1
        score[a] += 1
        score[b] -= 1

    received = [0] * n

    for i in range(n):
        for j in range(i + 1, n):
            if record[i][j] > record[j][i]:
                received[i] += 1
            elif record[i][j] < record[j][i]:
                received[j] += 1
            elif score[i] > score[j]:
                received[i] += 1
            elif score[i] < score[j]:
                received[j] += 1

    return max(received)
```

### 한 줄씩

- `index = {name: i ...}` → 친구 이름을 숫자 번호로 연결
- `record[a][b]` → a가 b에게 준 선물 개수
- `gift.split()` → 준 사람과 받은 사람의 이름 분리
- `record[a][b] += 1` → 두 사람 사이의 선물 기록 누적
- `score[a] += 1` → 준 사람의 선물 지수 증가
- `score[b] -= 1` → 받은 사람의 선물 지수 감소
- `received = [0] * n` → 다음 달 받을 개수 저장
- `range(i + 1, n)` → 각 친구 쌍을 한 번만 비교
- `record[i][j] > record[j][i]` → 상대에게 더 많이 준 사람이 받음
- `elif score[i] > score[j]` → 기록이 같을 때 선물 지수로 판단
- `max(received)` → 다음 달 받을 개수 중 최댓값 반환

### 시간 복잡도

친구 수를 `N`, 선물 기록 수를 `M`이라고 하면, 기록을 읽는 데 O(M), 모든 친구 쌍을 비교하는 데 O(N²)이 걸린다.

이름 길이가 최대 10인 제한사항에서, 딕셔너리 조회의 평균 시간 기준으로 **시간 복잡도는 O(M + N²)**이다.

이차원 선물 기록을 저장하므로 **공간 복잡도는 O(N²)**이다.

### 한 줄 요약

> 친구 쌍마다 서로 준 선물 수를 먼저 비교하고, 같을 때만 선물 지수를 비교해서 다음 달 받을 개수를 센다.
