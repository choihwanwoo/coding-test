# 코딩테스트 연습 - 중요한 단어를 스포 방지 (LV.1)

## 풀이

**1. 가려진 글자가 하나라도 있으면 스포 단어다.**

단어 전체가 가려져야 하는 것은 아니다.

`phone`에서 `o` 하나만 가려져 있어도 `phone` 전체를 스포 단어로 판단한다.

중요한 단어가 되려면 다음 조건을 만족해야 한다.

- 스포 단어여야 한다.
- 같은 단어가 처음부터 가려지지 않은 위치에 등장한 적이 없어야 한다.
- 앞서 공개한 스포 단어와 중복되지 않아야 한다.

여기서 비교하는 것은 단어의 일부가 아니라 **완전한 단어 문자열**이다.

<br>

**2. 각 문자에 스포 구간 번호를 표시한다.**

```python
hidden = [-1] * len(message)

for range_id, (start, end) in enumerate(spoiler_ranges):
    for i in range(start, end + 1):
        hidden[i] = range_id
```

- `-1` → 처음부터 보이는 문자
- `0`, `1`, `2`, ... → 해당 번호의 구간을 해제하면 보이는 문자

문제의 구간은 양 끝을 포함하므로 `end + 1`까지 반복한다.

구간들은 서로 겹치지 않아서, 표시하는 문자의 총개수는 메시지 길이를 넘지 않는다.

<br>

**3. 단어가 완전히 공개되는 구간을 찾는다.**

공백을 기준으로 단어를 읽으면서, 그 단어에 걸친 스포 구간 번호 중 최댓값을 구한다.

```python
last_range = max(last_range, hidden[i])
```

구간을 왼쪽부터 차례로 해제하므로, **가장 뒤의 구간까지 해제한 순간** 단어의 모든 글자가 공개된다.

<span style="color:red">ex)</span> `secret`에 0번 구간과 2번 구간이 걸쳐 있다면

- 0번 구간 해제 → 아직 가려진 글자가 남아 있음
- 2번 구간 해제 → 완전히 공개됨
- 따라서 2번 구간에서 판단할 단어로 저장

`last_range == -1`이면 단어의 모든 글자가 처음부터 보이는 상태다.

<br>

**4. 처음부터 보이는 단어와 공개할 단어를 나눠 저장한다.**

```python
if last_range == -1:
    visible.add(word)
else:
    revealed[last_range].append(word)
```

`visible`은 처음부터 보이는 단어를 담는 집합이다.

`revealed[k]`는 k번 구간을 해제했을 때 완전히 공개되는 단어들의 리스트다.

메시지를 왼쪽부터 읽으며 저장하므로, 같은 구간에서 여러 단어가 공개되어도 왼쪽부터 판단할 수 있다.

**처음부터 보이는 단어는 메시지 전체에서 먼저 수집해야 한다.**

뒤쪽에 같은 단어가 가려지지 않은 상태로 등장해도, 앞쪽 스포 단어는 중요한 단어가 될 수 없기 때문이다.

<br>

**5. 공개 순서대로 중복을 확인하며 센다.**

```python
if word not in visible and word not in seen:
    answer += 1
seen.add(word)
```

`seen`에는 이전에 공개된 스포 단어를 저장한다.

처음부터 보이는 단어에도 없고, 이전에 공개된 스포 단어에도 없을 때만 정답을 증가시킨다.

판단이 끝난 단어는 중요 여부와 관계없이 `seen`에 추가한다.

<br>

**6. 입출력 예에 적용해 본다.**

<span style="color:red">ex)</span> 첫 번째 예제

```python
message = "here is muzi here is a secret message"
spoiler_ranges = [[0, 3], [23, 28]]
```

- 첫 번째 구간에서 `here` 공개 → 다른 위치에 처음부터 보이는 `here`가 있으므로 제외
- 두 번째 구간에서 `secret` 공개 → 처음부터 보이지 않았고 중복도 없으므로 포함
- 결과: `1`

<span style="color:red">ex)</span> 두 번째 예제

```python
message = "my phone number is 01012345678 and may i have your phone number"
spoiler_ranges = [[5, 5], [25, 28], [34, 40], [53, 59]]
```

- 0번 구간 → `phone` 포함
- 1번 구간 → `01012345678` 포함
- 2번 구간 → `may`, `i` 포함
- 3번 구간 → `phone`은 이미 공개되어 제외, `number`는 처음부터 보이는 위치가 있어 제외
- 결과: `4`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. 스포 구간을 잘라서 `split()`하면 단어가 잘릴 수 있다.**

```python
message[start:end + 1].split()
```

`phone`의 `o`만 가려져 있으면 위 코드는 `o`만 가져온다.

하지만 판단할 단어는 `phone`이다. **원본 메시지에서 단어 전체를 읽고**, 그 안에 가려진 글자가 있는지 확인해야 한다.

<br>

**2. 가려지지 않은 글자 조각을 별도 단어로 세면 안 된다.**

`phone`에서 `o`만 가려져 있다고 해서 `ph`, `ne`가 처음부터 보이는 단어인 것은 아니다.

단어는 공백으로 구분한다. 가려진 글자가 하나라도 있는 단어 전체는 스포 단어다.

<br>

**3. 처음 걸친 구간에서 바로 세면 안 된다.**

한 단어가 여러 구간에 걸쳐 있으면 첫 구간을 해제해도 완전히 공개되지 않을 수 있다.

단어에 걸친 구간 번호의 **최댓값**으로 공개 시점을 정해야 한다.

<br>

**4. 처음부터 보이는 단어는 뒤쪽까지 확인해야 한다.**

```python
message = "cat cat"
spoiler_ranges = [[0, 2]]
```

앞의 `cat`은 가려졌지만 뒤의 `cat`은 처음부터 보인다.

따라서 결과는 `0`이다. 메시지를 읽는 도중 바로 정답을 세지 않고, 전체 단어를 분류한 뒤 공개 순서대로 판단한다.

<br>

**5. 공백만 가린 구간에서는 새 단어가 공개되지 않는다.**

```python
message = "a b"
spoiler_ranges = [[1, 1]]
```

가려진 인덱스는 공백이다. `a`, `b`의 글자는 모두 처음부터 보이므로 결과는 `0`이다.

## 정답

```python
def solution(message, spoiler_ranges):
    n = len(message)
    hidden = [-1] * n

    for range_id, (start, end) in enumerate(spoiler_ranges):
        for i in range(start, end + 1):
            hidden[i] = range_id

    visible = set()
    revealed = [[] for _ in spoiler_ranges]
    i = 0

    while i < n:
        if message[i] == ' ':
            i += 1
            continue

        start = i
        last_range = -1

        while i < n and message[i] != ' ':
            last_range = max(last_range, hidden[i])
            i += 1

        word = message[start:i]

        if last_range == -1:
            visible.add(word)
        else:
            revealed[last_range].append(word)

    answer = 0
    seen = set()

    for words in revealed:
        for word in words:
            if word not in visible and word not in seen:
                answer += 1
            seen.add(word)

    return answer
```

### 한 줄씩

- `hidden = [-1] * n` → 각 문자의 스포 구간 번호를 저장할 배열
- `range(start, end + 1)` → 양 끝을 포함해서 구간 표시
- `visible = set()` → 처음부터 보이는 단어를 중복 없이 저장
- `revealed = [[] for _ in spoiler_ranges]` → 구간별로 완전히 공개될 단어 저장
- `last_range = max(last_range, hidden[i])` → 단어가 완전히 공개되는 구간 찾기
- `word = message[start:i]` → 원본 메시지에서 단어 전체 추출
- `revealed[last_range].append(word)` → 해당 구간에 단어를 왼쪽부터 저장
- `word not in visible and word not in seen` → 처음부터 보이는 단어와 이전에 공개된 단어 제외
- `seen.add(word)` → 지금 공개한 스포 단어 기록
- `return answer` → 중요한 단어 개수 반환

### 시간 복잡도

메시지 길이를 `N`, 스포 구간 개수를 `R`이라고 하면, 집합 연산이 평균적으로 상수 시간이라는 기준에서 **시간 복잡도는 O(N + R)**이다.

구간이 겹치지 않아 문자 표시가 최대 N번이고, 단어를 읽고 집합에서 확인하는 문자열들의 전체 길이도 O(N)이다.

문자별 구간 번호와 단어들을 저장하므로 **공간 복잡도도 O(N + R)**이다.

### 한 줄 요약

> 단어에 걸친 마지막 스포 구간을 공개 시점으로 잡고, 처음부터 보이는 단어와 이미 공개한 단어를 제외해 센다.
