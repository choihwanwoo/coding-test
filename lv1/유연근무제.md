# 코딩테스트 연습 - 유연근무제 (LV.1)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/388351)

## 풀이

**1. 평일 모두 출근 희망 시각 + 10분 이내에 출근해야 한다.**

직원마다 출근 희망 시각이 다르다.

각 직원의 허용 시각을 구하고, 평일에 한 번이라도 그 시각보다 늦게 출근했다면 제외한다.

- 허용 시각과 같으면 인정
- 토요일과 일요일의 기록은 무시
- 평일 5일을 모두 통과한 직원만 상품을 받음

<br>

**2. 시각을 분으로 바꾼 뒤 10분을 더한다.**

입력은 `시 * 100 + 분` 형태다. 따라서 단순히 10을 더하면 안 된다.

```python
limit = (schedule // 100) * 60 + schedule % 100 + 10
```

- `schedule // 100` → 시
- `schedule % 100` → 분
- `시 * 60 + 분` → 0시부터 지난 총 분

<span style="color:red">ex)</span> `schedule = 855`

```text
8시 55분 → 8 * 60 + 55 = 535분
10분 추가 → 545분 → 9시 5분
```

실제 출근 시각도 같은 방식으로 분으로 바꾼다.

```python
arrival = (time // 100) * 60 + time % 100
```

분끼리 비교하면 시가 넘어가더라도 별도 처리가 필요 없다.

<br>

**3. 시작 요일을 기준으로 매일의 요일을 계산한다.**

날짜 인덱스 `day`는 첫날을 `0`으로 센다.

```python
weekday = (startday - 1 + day) % 7
```

이 식에서는 월요일부터 일요일까지를 `0~6`으로 나타낸다.

- `0~4` → 월요일~금요일
- `5` → 토요일
- `6` → 일요일

따라서 `weekday >= 5`면 검사하지 않는다.

```python
if weekday >= 5:
    continue
```

<span style="color:red">ex)</span> 금요일에 시작하면 `startday = 5`

```text
날짜 인덱스: 0  1  2  3  4  5  6
요일:        금 토 일 월 화 수 목
weekday:     4  5  6  0  1  2  3
```

이때는 인덱스 `1`, `2`의 기록을 제외해야 한다.

<br>

**4. 평일 지각이 나오면 해당 직원의 검사를 끝낸다.**

```python
if arrival > limit:
    eligible = False
    break
```

처음에는 `eligible = True`로 시작한다.

평일 지각을 발견하면 `False`로 바꾸고 반복문을 종료한다. 이미 상품을 받을 수 없으므로 남은 기록은 확인할 필요가 없다.

일주일 검사 후에도 `eligible`이 `True`라면 정답을 1 증가시킨다.

<br>

**5. 예제에 적용해 본다.**

<span style="color:red">ex)</span> 첫 번째 예제

- 희망 시각 → `7:00`, `8:00`, `11:00`
- 허용 시각 → `7:10`, `8:10`, `11:10`
- 금요일 시작이므로 두 번째, 세 번째 날은 주말
- 주말을 제외하면 직원 3명 모두 허용 시각 이내에 출근
- 결과 → `3`

<span style="color:red">ex)</span> 두 번째 예제

- 월요일 시작이므로 첫 5일만 검사
- 첫 번째 직원 → 허용 시각 `7:40`, 평일 모두 통과
- 두 번째 직원 → 허용 시각 `9:05`, 월요일 `9:08`로 탈락
- 세 번째 직원 → 허용 시각 `7:10`, 평일 모두 통과
- 네 번째 직원 → 허용 시각 `7:30`, 화요일 `7:31` 등으로 탈락
- 결과 → `2`

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. HHMM 형태의 숫자에 10을 바로 더하면 안 된다.**

```python
855 + 10  # 865 → 올바른 시각 표현이 아님 ❌
```

8시 55분의 10분 뒤는 9시 5분이다.

총 분으로 변환한 뒤 10을 더하면 올바르게 비교할 수 있다.

<br>

**2. 마지막 두 기록이 항상 주말은 아니다.**

마지막 두 기록이 주말인 경우는 월요일에 시작했을 때다.

금요일이나 일요일에 시작할 수도 있으므로 `startday`로 실제 요일을 계산해야 한다.

<br>

**3. 허용 시각과 같으면 지각이 아니다.**

```python
if arrival > limit:  # 지각 ✅
```

`>=`를 사용하면 정확히 10분 뒤에 출근한 직원도 탈락시킨다.

예를 들어 희망 시각이 `7:00`이면 `7:10`까지 인정된다.

<br>

**4. 지각한 날이 아니라 조건을 만족한 직원 수를 센다.**

한 직원이 평일에 여러 번 지각해도 탈락하는 직원은 한 명이다.

직원별로 검사한 뒤, 모든 평일을 통과했을 때만 정답을 1 증가시킨다.

<br>

**5. 직원마다 판정 상태를 새로 초기화해야 한다.**

```python
for schedule, logs in zip(schedules, timelogs):
    eligible = True
```

이전 직원이 탈락했더라도 다음 직원은 다시 `True`로 시작해야 한다.

## 정답

```python
def solution(schedules, timelogs, startday):
    answer = 0

    for schedule, logs in zip(schedules, timelogs):
        limit = (schedule // 100) * 60 + schedule % 100 + 10
        eligible = True

        for day, time in enumerate(logs):
            weekday = (startday - 1 + day) % 7

            if weekday >= 5:
                continue

            arrival = (time // 100) * 60 + time % 100

            if arrival > limit:
                eligible = False
                break

        if eligible:
            answer += 1

    return answer
```

### 한 줄씩

- `zip(schedules, timelogs)` → 같은 직원의 희망 시각과 일주일 기록을 함께 가져오기
- `schedule // 100` → 희망 시각의 시 추출
- `schedule % 100` → 희망 시각의 분 추출
- `limit = ... + 10` → 분 단위로 허용 시각 계산
- `eligible = True` → 해당 직원의 상품 대상 여부 초기화
- `enumerate(logs)` → 날짜 인덱스와 출근 시각을 함께 가져오기
- `(startday - 1 + day) % 7` → 월요일을 0으로 둔 요일 계산
- `weekday >= 5` → 토요일과 일요일 제외
- `arrival = ...` → 실제 출근 시각을 분으로 변환
- `arrival > limit` → 허용 시각보다 늦었는지 확인
- `break` → 해당 직원의 남은 기록 검사 종료
- `if eligible:` → 평일 지각이 없는 직원만 집계
- `return answer` → 상품을 받을 직원 수 반환

### 시간 복잡도

직원 수를 `N`이라고 하면 직원마다 최대 7개의 기록을 검사한다.

따라서 **시간 복잡도는 O(7N) = O(N)**이고, 별도의 배열을 만들지 않으므로 **추가 공간 복잡도는 O(1)**이다.

### 한 줄 요약

> 시각을 분으로 바꿔 10분의 여유를 더하고, 시작 요일에 맞춰 주말을 제외한 모든 날에 지각하지 않은 직원을 센다.
