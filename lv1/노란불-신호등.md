# 코딩테스트 연습 - 노란불 신호등 (LV.1)

[문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/468371)

## 풀이

**1. 신호등 하나의 주기는 초록불 + 노란불 + 빨간불이다.**

신호등은 초록불 → 노란불 → 빨간불 순서로 반복된다.

```python
cycle = green + yellow + red
```

<span style="color:red">ex)</span> `[2, 1, 2]`

- 1~2초 → 초록불
- 3초 → 노란불
- 4~5초 → 빨간불
- 6초부터 같은 순서로 반복

따라서 주기는 `5`초다.

<br>

**2. 시간은 1초부터 시작하므로 `t - 1`로 계산한다.**

```python
position = (t - 1) % cycle
```

`%`는 나눈 나머지를 구한다. 시간에서 1을 빼고 주기로 나누면, 현재 주기 안에서의 위치를 `0`부터 셀 수 있다.

초록불이 `green`초, 노란불이 `yellow`초라면 노란불인 조건은 다음과 같다.

```python
green <= position < green + yellow
```

<span style="color:red">ex)</span> `[2, 1, 2]`의 3초

```python
position = (3 - 1) % 5  # 2
2 <= 2 < 3             # True → 노란불
```

초록불 위치는 `0, 1`, 노란불 위치는 `2`, 빨간불 위치는 `3, 4`다.

<br>

**3. 모든 신호등이 함께 반복되는 주기를 구한다.**

답이 없는 경우도 있어서 무한히 시간을 증가시키면 안 된다.

각 신호등의 주기의 **최소공배수**를 `limit`으로 잡는다.

```python
limit = limit * cycle // gcd(limit, cycle)
```

`gcd(a, b)`는 두 수의 최대공약수이고, 최소공배수는 `a * b // gcd(a, b)`로 구한다.

<span style="color:red">ex)</span> 주기가 `5`초와 `7`초라면

- 최소공배수는 `35`
- 36초의 전체 상태는 1초의 전체 상태와 같음
- 37초의 전체 상태는 2초의 전체 상태와 같음

따라서 **1초부터 35초까지** 확인했는데 답이 없다면 이후에도 답이 없다.

<br>

**4. 1초부터 확인해서 모두 노란불이면 바로 반환한다.**

```python
for t in range(1, limit + 1):
```

각 시각마다 신호등을 하나씩 확인한다.

노란불이 아닌 신호등이 하나라도 있으면 `break`로 다음 시각으로 넘어간다.

모든 신호등이 노란불이면 그 시각을 반환한다. 시간을 작은 순서로 확인하므로 처음 찾은 값이 가장 빠른 시각이다.

끝까지 찾지 못하면 `-1`을 반환한다.

<br>

**5. 문제에 나온 예시에 적용해 본다.**

```python
signals = [[2, 1, 2], [5, 1, 1]]
```

- 첫 번째 신호등의 노란불 시각 → `3, 8, 13, 18, ...`
- 두 번째 신호등의 노란불 시각 → `6, 13, 20, 27, ...`
- 처음 겹치는 시각 → `13`

결과는 `13`이다.

## 오답노트

아래는 구현할 때 주의할 점이다.

**1. `t % cycle`을 쓰면 시간이 한 칸 밀린다.**

1초가 초록불의 첫 번째 위치인 `0`에 대응해야 한다.

```python
(t - 1) % cycle  # ✅
```

`[2, 1, 2]`에서 `t % 5`를 사용하면 2초를 노란불로 잘못 판단하게 된다.

<br>

**2. 노란불의 끝 경계는 포함하지 않는다.**

```python
green <= position < green + yellow
```

`position == green + yellow`이면 이미 빨간불이다.

노란불이 여러 초 지속되는 경우도 있으므로 `position == green`만 확인해서도 안 된다.

<br>

**3. 답이 없을 수 있으므로 탐색 종료 조건이 필요하다.**

```python
signals = [[1, 1, 1], [2, 1, 3]]
```

- 첫 번째 신호등은 `2, 5, 8, 11, ...`초에 노란불
- 두 번째 신호등은 `3, 9, 15, 21, ...`초에 노란불
- 두 신호등이 동시에 노란불이 되는 경우는 없음

전체 반복 주기인 `6`초까지 확인한 뒤 `-1`을 반환하면 된다.

<br>

**4. `for ... else`의 `else`는 반복문이 정상 종료될 때 실행된다.**

```python
for green, yellow, cycle in cycles:
    if not green <= (t - 1) % cycle < green + yellow:
        break
else:
    return t
```

여기서 `else`는 `if`가 아니라 **for문에 연결**된다.

- `break` 발생 → 노란불이 아닌 신호등이 있으므로 `else` 실행 안 함
- `break` 없이 전부 확인 → 모두 노란불이므로 `else` 실행

들여쓰기 위치를 주의해야 한다.

## 정답

```python
from math import gcd


def solution(signals):
    cycles = []
    limit = 1

    for green, yellow, red in signals:
        cycle = green + yellow + red
        cycles.append((green, yellow, cycle))
        limit = limit * cycle // gcd(limit, cycle)

    for t in range(1, limit + 1):
        for green, yellow, cycle in cycles:
            position = (t - 1) % cycle

            if not green <= position < green + yellow:
                break
        else:
            return t

    return -1
```

### 한 줄씩

- `from math import gcd` → 최대공약수를 구하는 함수 가져오기
- `cycles = []` → 각 신호등의 초록불 시간, 노란불 시간, 주기 저장
- `limit = 1` → 최소공배수를 누적하기 위한 초기값
- `cycle = green + yellow + red` → 신호등 하나의 전체 주기
- `limit * cycle // gcd(limit, cycle)` → 전체 반복 주기 갱신
- `range(1, limit + 1)` → 한 전체 주기 동안 시각 확인
- `(t - 1) % cycle` → 현재 신호등의 주기 안에서 위치 계산
- `green <= position < green + yellow` → 노란불 여부 확인
- `break` → 하나라도 노란불이 아니면 다음 시각 확인
- `else: return t` → 모두 노란불이면 가장 빠른 시각 반환
- `return -1` → 한 주기 동안 없으면 불가능

### 시간 복잡도

신호등 개수를 `N`, 모든 주기의 최소공배수를 `L`이라고 하면 탐색 시간 복잡도는 **O(N × L)**이고, 추가 공간 복잡도는 **O(N)**이다.

이 문제는 신호등이 최대 `5`개이고 각 주기가 최대 `20`이므로, `L`은 각 주기를 곱한 값인 `20⁵ = 3,200,000` 이하이다. 제한사항 안에서 한 전체 주기를 탐색할 수 있다.

### 한 줄 요약

> `(t - 1) % 주기`로 노란불인지 확인하고, 모든 주기의 최소공배수만큼 탐색해서 가장 빠른 시각을 찾는다.
