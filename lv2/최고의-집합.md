# 코딩테스트 연습 - 최고의 집합 (LV.2)

이번 문제는 감이 잘 안 와서 거의 손도 못 댔다.  
틀만 잡다가 막혀서, 나중에 로직을 정리했다.

## 풀이

**1. 최고의 집합 = 합이 `s`이면서 곱이 최대인 자연수 `n`개**

자연수 `n`개를 더해서 `s`가 되게 만들고,  
그중 **곱이 가장 큰** 조합을 오름차순 배열로 반환한다.

만들 수 없으면 `[-1]`을 반환한다.

<span style="color:red">ex)</span> `n = 2`, `s = 9`

- 가능한 집합: `{1,8} {2,7} {3,6} {4,5}`
- 곱이 가장 큰 건 `{4,5}` → `[4, 5]`

<br>

**2. 핵심: 숫자들을 최대한 비슷하게 만든다.**

합이 고정이면, 곱을 크게 하려면 값들이 **서로 비슷**해야 한다.

그래서 거의 전부 `s / n`으로 채우고,  
남는 나머지(`s % n`)만 하나씩 `+1` 해 주면 된다.

```java
int base = s / n;   // 기본값
int left = s % n;   // 뒤에 +1 할 개수
```

<span style="color:red">ex)</span> `n = 2`, `s = 9`

- `9 / 2 = 4`, `9 % 2 = 1`
- 일단 `[4, 4]`
- 뒤에서부터 1개에 `+1` → `[4, 5]`

<br>

**3. 불가능한 경우부터 걸러낸다.**

자연수 최소값이 1이므로, `n`개의 최소 합은 `n`이다.

`s < n`이면 불가능 → `[-1]`

```java
if (s < n) {
    return new int[]{-1};
}
```

<br>

**4. 배열을 채운 뒤, 나머지만큼 뒤에서 +1 한다.**

오름차순으로 반환해야 해서, `+1`은 **뒤쪽부터** 한다.

```java
for (int i = 0; i < n; i++) {
    answer[i] = base;
}

for (int i = 0; i < left; i++) {
    answer[n - 1 - i]++;
}
```

<span style="color:red">ex)</span>

- `n=2, s=8` → `[4, 4]`
- `n=2, s=1` → `[-1]`

## 오답노트

**1. 거의 손도 못 댔다.**

Lv.0이랑 결이 달랐다.  
합·곱·집합이라는 말만 보고는 뭘 해야 할지 감이 안 왔다.

나중에 알고 보니 핵심은 하나였다.

> 합이 같으면, 숫자들이 비슷할수록 곱이 크다.

이 한 줄을 모르면 구현으로 넘어가기 어렵다.

<br>

**2. 틀만 짜다가 문법에서 막혔다.**

```java
if (s > 1) {
    s
} else {
    answer = -1;
}
```

문제점:

- `s > 1`이 아니라 `s < n`이 불가능한 조건
- `s`만 덩그러니 있으면 문법 에러
- `answer`는 `int[]`인데 `-1`은 `int`라서 대입 불가

불가능할 때는 이렇게 반환한다.

```java
return new int[]{-1};
```

<br>

**3. `[-1]` 반환 방식을 몰랐다.**

배열을 이미 `new int[n]`으로 만들어 둔 뒤 `answer = -1` 하면 안 된다.

아예 `return new int[]{-1};`로 끝내는 게 깔끔하다.

---

## 정답

```java
class Solution {
    public int[] solution(int n, int s) {
        if (s < n) {
            return new int[]{-1};
        }

        int[] answer = new int[n];
        int base = s / n;
        int left = s % n;

        for (int i = 0; i < n; i++) {
            answer[i] = base;
        }

        for (int i = 0; i < left; i++) {
            answer[n - 1 - i]++;
        }

        return answer;
    }
}
```

### 한 줄 요약

> 불가능하면 `[-1]` → 전부 `s/n`으로 채움 → 나머지만큼 뒤에서 `+1`
